# 홍동님 전달용 안내문

홍동님, 24×24 초록 조립판의 영상 픽셀을 판 기준 X/Y(mm)와 행·열로 변환하는 코드와 현재 측정 결과를 정리했습니다.

압축을 푼 뒤 `HANDOFF_STATUS.md`로 검증 상태를 확인하고, `HONGDONG_VISION_GUIDE.md`의 Python API/ROS 예제를 따라 비전 노드에 연결하면 됩니다. `runs/view01/calibration.json`이 변환 데이터이고, `vision_coordinates.py`가 기존 검출기의 원본 영상 중심 좌표를 받아 판 좌표로 바꾸는 함수입니다. 0부터 세는 행·열 출력도 제공합니다.

현재 검증 결과는 최대 1.655 mm, RMSE 1.260 mm로 초기 최대 1.5 mm 기준은 아직 통과하지 못했습니다. 블록 윗면 높이와 실제 검출 중심 검증도 남아 있습니다. 현재 초안은 개발·시각화 시험용이며, 미검증 결과를 명시적으로 허용할 때만 예제를 실행할 수 있습니다. 최종 전달본의 상태와 수치는 `HANDOFF_STATUS.md`를 기준으로 확인해주세요.

기존 변환은 같은 카메라와 같은 손목 촬영 자세에서만 사용할 수 있습니다. 홍동님 로컬의 카메라 위치가 다르면 `README_ko.md` 절차로 재캘리브레이션해야 합니다. 판 좌표는 카메라 XYZ나 로봇 베이스 XYZ가 아니므로 기존 로봇 이동 서비스에 그대로 넣지 않고 별도 판 좌표 출력으로 연결합니다.
