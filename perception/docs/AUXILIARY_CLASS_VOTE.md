# B 보조 클래스 투표 — 구현 및 활성화 조건

2026-10-12. 클래스 투표는 Expected에 맞추는 기능이 아니라 동일 정적 관측 묶음의 실제 근거 통합 보조다. 공통 Observed 및 D 계약은 바꾸지 않는다.

- main.observe_cycle은 View별 측정 후보의 실수 Board 중심(surface_center_m)·높이(top_height_m)를 보존한다. 클래스별 anchor만으로 연결하지 않는다.
- V0/D1/D3 전체 입력 이후에만 보조 투표한다. 부분 결과에는 투표하지 않는다.
- 기하 검증을 통과한 CANDIDATE가 유효표다. UNKNOWN은 현재 측정 경로에서 연결 위치/높이가 보존되지 않아 기권한다. layer만 미확인인 별도 후보의 클래스 투표는 그 후보의 유효한 위치·클래스 근거를 생산하는 추가 경로가 필요하며 현재 지원 완료가 아니다.
- 단일 유효표는 해당 블록만 유지한다. 타 View의 미확인 사유나 전체 완료 조건을 삭제하지 않는다.
- 2대1/3대0은 지지된 클래스를 선택하되 같은 클래스의 배치 충돌, 명시적 기하 충돌, 연결 모호성은 보류한다. 1대1은 동률이다. 기권은 반대표가 아니다.
- 잘못된 클래스의 관측을 이긴 클래스의 새 검출처럼 만들지 않는다. 패한 후보 및 해당 View의 충돌 확인 영역은 제외한다. 확인된 빈 영역과의 충돌은 기존 통합 검사에서 계속 보류된다.
- diagnostics.class_vote_log에 View·표 수·채택 클래스·기권/보류 사유를 별도 기록한다. 측정 단위는 m다. 안정되지 않은 scene·다른 check/sequence/calibration·중복 View는 기존 거절 기준을 유지한다.

## 활성화

호출 시 geometry config에 class_vote_policy를 명시적으로 제공해야 한다. 없으면 기존 통합 판정 그대로다. 필요한 키는 center_tolerance_m과 height_tolerance_m이며 실제 같은 블록/인접 다른 블록의 시점별 중심·높이 오차를 비교해 채택해야 한다. 자동 예시값/기본값은 제공하지 않는다. 현재 운영 설정에는 이 값이 미채택이므로 활성화되지 않았다.

이 경로는 통합 사이클 main.observe_cycle → build_observed → merge_views에 연결됐다. live_view의 시점별 프레임은 아직 사이클 통합 결과를 받아 표시하는 경로가 아니므로 그 화면이 투표 확정값으로 바뀐다고 주장하지 않는다. replay/SDK 독립 경로에 자동 적용됐다고도 주장하지 않는다.

테스트의 .002/.003m 등은 합성 fixture 전용이며 실물 기준이 아니다. 실제 정답 데이터의 기존 대비 오답/보류 비교 및 운영 활성화는 남은 작업이다.
