# 4층 고정 자세 반복 측정

View별 3장의 실제 RGB-D를 이전 4층과 동일한 픽셀 윗면 ROI로 분석했습니다. 새 모델·합성 입력·운영 보정 변경은 없습니다. 이미지에서 ROI를 확인할 수 있으며 AI 수동 선택의 사람 검수는 별도입니다.

| View | 높이 중앙값 3회 (mm) | 최대−최소 (mm) | nonzero Depth 비율 |
| --- | --- | ---: | --- |
| V0 | 76.50 / 77.25 / 76.03 | 1.22 | 99.67 / 99.92 / 99.59% |
| D1 | 80.04 / 80.33 / 80.52 | 0.48 | 100 / 100 / 100% |
| D3 | 79.02 / 79.65 / 79.84 | 0.82 | 99.93 / 100 / 99.93% |

이번 고정 4층 장면에서 프레임별 중앙값 변동은 위 범위입니다. 층별/다른 위치/색상/가림의 정확도 검증이나 보드 스터드 윗면 기준 높이 확정은 아닙니다. View별 4층 높이 차이도 남아 있으므로 통합 허용 오차나 층 임계값을 임의 설정하지 않았습니다.

각 프레임의 입력 경로·ROI·측정 분포·한계는 `repeat_height_report.json`에, 영역 이미지는 `View_시각_top_roi.png`에 저장했습니다. 수집 및 참고 분석은 완료했으며 기존 기준면 검증 문제는 미해결 상태입니다. 다음은 별도 네 클래스 RGB-D 촬영 및 사람이 작성하는 YOLO mask 라벨링을 병행하는 단계입니다. 반복 영상은 연속 동일 장면이므로 train/validation 양쪽으로 나누지 않습니다.
