## 해석 및 미검증

- 분석 영역은 원점 stud부터 23번 stud까지의 중심 사각형에서 한 stud 간격을 안쪽으로 제외한 영역입니다. 테이블·보드 가장자리를 제외하기 위한 ROI이며 전체 보드나 `verified_regions`가 아닙니다.
- PNG/NPY 값 일치, uint16 Depth 형식, RGB/Depth 크기, View, RGB 보정과 카메라 내부 파라미터 일치를 확인했습니다. 메타데이터의 세 영상 시각 차이는 모두 0 ms입니다.
- 카메라 광축 Z는 카메라 기준 거리 성분이며 보드 높이가 아닙니다. 보드 Z는 기존 RGB 기반 회전·이동값을 역변환해 계산했습니다.
- 빈 보드라면 기준면 부근이어야 하지만 +18~26 mm의 중앙값 차이가 있습니다. stud 윗면과 사이의 낮은 면이 섞이는 점도 고려해야 하며, 이 값을 그대로 블록 높이 또는 새로운 Z=0으로 채택하지 않았습니다.
- 지배 평면은 보드 좌표에서 `z = a*x + b*y + c`로 계산합니다. 초기 높이 및 반복 잔차의 MAD 기반 이상값 제외(3×1.4826×MAD, 최소 1 mm)는 분석용 방법일 뿐 통과 임계값이 아닙니다. RMSE는 이상값 제외 후 값이며 D1 전체 Depth 품질을 대표하지 않습니다. 원자료 분포와 사용 비율은 JSON에 함께 남겼습니다.
- RGB 평면 검증의 2 mm 기준을 Depth 높이에 적용하지 않았습니다. Depth/층 허용 기준은 미합의이고 각 View 한 프레임만 있어 시간 반복성도 미검증입니다.
- 촬영 메타데이터의 robot_pose/calibration_id는 비어 있습니다. 같은 View 이름·카메라 정보만으로 실제 자세 동일성을 증명하지는 못합니다.

## 산출물

각 View의 `depth_baseline_review/` 폴더:

- `depth_baseline_report.json`: 실제 측정값·분포·평면·한계 기록
- `depth_roi_review.png`: 분석 영역(초록)과 0값 Depth 누락(빨강) 확인 이미지

**결론: 촬영 데이터 분석은 수행했으나 Depth 기준 높이 검증 통과 또는 층 판별 준비 완료로 표시하지 않습니다.**
