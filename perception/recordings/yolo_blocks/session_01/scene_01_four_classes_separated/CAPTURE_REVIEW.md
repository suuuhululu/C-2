# 네 클래스 분리 배치 촬영 검토

V0·D1·D3에서 네 블록이 각각 보이는 실제 RGB-D를 확인했습니다. RGB와 aligned Depth의 PNG/NPY 일치도 확인했습니다. 원본은 수정하지 않았습니다.

OpenCV HSV 진단 범위는 노랑 H18~40/S80~255/V60~255, 파랑 H95~135/S80~255/V25~255입니다. 이번 영상 점검용 임시값으로 운영 기준·검수된 mask가 아닙니다. 가장 큰 파란 연결 영역을 고르면 D1의 보드 바깥 배경을 고르는 문제가 있어, D1 파란 블록은 RGB에서 확인한 블록 위치의 영역으로 제한하여 다시 분석했습니다. 색상만으로 블록 크기를 판별하지 않았습니다.

V0 노란 2×3의 밝은 반사 부분은 HSV 색상 mask에서 많이 빠집니다. 원본 RGB의 외곽은 보이므로 사람 수동 polygon 작성은 가능하지만 자동 색상 mask를 그대로 학습 라벨로 사용하지 않습니다. D1 노란 영역의 nonzero Depth 비율은 두 블록에서 약95.84%와97.44%, D3는 약99.84%와100%입니다. 나머지 View의 파란 블록 선택 색상 영역에서는 0값 누락이 관찰되지 않았습니다. 이 수치는 선택 색상 영역만의 품질이고 윗면 전체의 높이·층 검증이 아닙니다.

실제 RGB 3장은 `perception/labeling/yolo_blocks_session_01/`에 정리했고 provenance에 원본 경로와 해시를 보존했습니다. 사람이 아직 mask를 작성하거나 검수한 것은 아닙니다. 다음은 기존 labeling annotate로 네 블록의 보이는 전체 영역을 각각 작성·검수합니다. 학습 클래스 번호는 0 yellow_2x2, 1 yellow_2x3, 2 blue_2x2, 3 blue_2x3입니다.

현재 한 촬영 세션만 확보했습니다. 같은 세션의 세 View를 train/validation에 나누지 않습니다. 추가 독립 장면·네 클래스 및 접촉·적층·가림 조건을 확보하기 전 학습 준비 완료로 표시하지 않습니다.
