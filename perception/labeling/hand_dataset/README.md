# 손 검출 라벨 초안 — 2026-10-10

원본: `/home/roh/Videos/Screencasts/손 yolo학습 시켜야 할 거.mp4`

약 39.45초 영상에서 0~38초를 2초 간격으로 추출한 실제 RGB 20장이다.
블록 모델과 별도인 Object Detection 데이터이며 클래스는 `0: hand`다.
영상에서 손의 보이는 범위를 육안으로 확인해 사각형 라벨을 작성했다.
팔 전체가 아니라 손가락·손바닥에서 손목 경계까지를 대상으로 한다.
부분 가림은 보이는 손 기준이며 손에 쥔 블록이 사각형 안에 포함될 수 있다.

## 파일

- `images/train`: 라벨 초안 검수 후보 PNG 16장. 사람 검수 완료를 뜻하지 않는다.
- `labels/train`: 각 PNG에 대응하는 YOLO detection TXT 16개.
- `review_required/images`, `review_required/labels`: 흐림/극소 경계손으로 보류한 4장과 라벨 초안. 기본 후보와 분리했다.
- `previews`: 각 사진의 빨간 손 사각형 미리보기 및 `contact_1.jpg`~`contact_5.jpg` 전체 검수 모음.
- `classes.txt`: `hand` 클래스 이름.
- `provenance.json`: 원본 영상과 SHA256, 요청 추출 시각, 동일 장면 ID, 이미지 SHA256, 라벨 수, AI 초안/사람 검수 미완료 표시.

TXT 형식: `0 x_center y_center width height` (이미지 크기로 정규화).
22초 사진은 보이는 손이 없는 배경 후보로 빈 TXT를 저장했다.
총 35개 손 사각형 초안이며, 보류한 4장의 8개를 제외하면 27개다.
원본 RGB PNG에는 상자를 그리지 않았으며 미리보기 JPG에만 표시했다.

## 사용 전 확인

1. 미리보기에서 손가락 누락·손목 범위·화면 가장자리 손·빈 사진 여부를 사람이 확인하고 필요 시 수정한다.
2. 이 데이터만으로 인식 정확도·안전 또는 손 이탈 시간 판정을 보장하지 않는다.
3. 모두 같은 영상/장면이다. 연속 프레임을 무작위로 train/val에 나누지 않는다.
4. 다른 촬영 세션의 손 진입·이탈 및 손 없는 장면을 추가하여 독립 검증 세트를 만든다.
5. 독립 검증 자료가 없어 학습 가능한 `data.yaml`이나 실제 학습 모델은 생성하지 않았다. 학습은 별도 작업이다.

OpenCV 동영상 seek가 선택한 프레임의 정확한 PTS는 검증하지 않았다.
촬영 시각/시간 조건 시험 로그가 아니라 학습 라벨 준비 자료다.
보류 사진은 삭제하지 않았으며 자동으로 학습에 포함하지 않는다.
