# 고정 드릴 설정 개발 위치

2026-09-20 main `72618aa` 확인 기준 `workcell.yaml`·`tools.yaml` 실행 파일은 아직 없다. [운영 결정과 미확정 값](../../../../docs/C2_FIXED_DRILL_20260919.md)을 기준으로 담당자가 검증된 설정을 작성한다.

- workcell: `frame_id=c2_base`, 고정 대상·이음매·작업 영역, J6 경로 검증 조건을 명시한다. 현재 공정에는 청소면을 정의하지 않는다.
- 받침대 50 mm는 보고된 설치 변경이다. z≈234.4 mm는 예상치라 실행값으로 입력하지 않는다. 재측정 시 TCP·접촉부·자세·프레임·시각·근거와 버전을 함께 기록한다.
- tools: `engraving_drill`, `GripperDA_v1` 그리퍼 끝점, 하중·고정 장착 정책·관측 기준·가공·보정 근거를 관리한다. 열기/집기/반납/청소 설정은 현재 미사용이며 실행 기본 동작으로 복원하지 않는다.
- 오프셋·거리·`clearance_m`는 m. 어댑터 프로파일 `vel_mm_s`, `acc_mm_s2`, `pos_tol_mm`는 각각 mm/s, mm/s², mm이며 단위를 이름에 유지한다.
- 보정은 새 불변 설정 스냅샷으로 연결한다. 실제 값·한계가 없으면 REAL 준비를 거절하며 가짜 0이나 과거 값을 넣지 않는다.

[9/18 측정 evidence](../../../../docs/evidence/workcell_candle_0918.yaml)는 당시 기록으로 보존한다. 새 50 mm 받침대 실행 설정으로 덮어쓰거나 그대로 복사하지 않는다.

## 담당과 기준 모델·실측값 분리

- 이시율: workcell·도구·이동/접촉/가공 설정과 측정 근거 작성. 노홍동은 기준 경로 모델·단위·영역을 대조하고 김세은은 로딩·검증·공정 연결을 맡는다.
- `workcell.yaml`의 기준 양초 모델을 매 작업 실측값으로 덮어쓰지 않는다. 양초 중심·축/기울기·반지름·측정 시각·유효성·잔차는 별도 불변 측정 스냅샷으로 연결한다. 정확한 저장 필드는 통합 전 합의한다.
- 도구 장착 보정과 양초 측정 기록을 분리한다. 기존 경로와 실제 중심의 차이 자체는 오류가 아니며 실측 변환으로 새 실행 경로를 만든다. 기존 1점 도구 확인만으로 양초 이동과 드릴 이동을 구분할 수는 없다.
- 원본 경로·도구/설정·실측·최종 실행 경로·검사 결과를 ID·버전·해시로 묶는다. [새 공정 흐름](../README.md)의 최종 표시·검사·실행 경로가 같아야 한다.
- 목표 깊이 0.5 mm·허용오차 ±0.3 mm·최대 깊이 1.0 mm는 사용자가 제시한 검증 목표다. 실물 깊이 달성값이나 힘에서 바로 환산되는 값이 아니다. 첫 하트 실험의 모델상 깊이 0.3 mm와 구분하며 검증되지 않은 힘 적응 폭을 기본값으로 확정하지 않는다.
