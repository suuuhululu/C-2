# 고정 드릴 설정 개발 위치

2026-09-19 현재 `workcell.yaml`·`tools.yaml` 실행 파일은 아직 없다. [운영 결정과 미확정 값](../../../../docs/C2_FIXED_DRILL_20260919.md)을 기준으로 담당자가 검증된 설정을 작성한다.

- workcell: `frame_id=c2_base`, 고정 대상·이음매·작업 영역, J6 경로 검증 조건을 명시한다. 현재 공정에는 청소면을 정의하지 않는다.
- 받침대 50 mm는 보고된 설치 변경이다. z≈234.4 mm는 예상치라 실행값으로 입력하지 않는다. 재측정 시 TCP·접촉부·자세·프레임·시각·근거와 버전을 함께 기록한다.
- tools: `engraving_drill`, `GripperDA_v1` 그리퍼 끝점, 하중·고정 장착 정책·관측 기준·가공·보정 근거를 관리한다. 열기/집기/반납/청소 설정은 현재 미사용이며 실행 기본 동작으로 복원하지 않는다.
- 오프셋·거리·`clearance_m`는 m. 어댑터 프로파일 `vel_mm_s`, `acc_mm_s2`, `pos_tol_mm`는 각각 mm/s, mm/s², mm이며 단위를 이름에 유지한다.
- 보정은 새 불변 설정 스냅샷으로 연결한다. 실제 값·한계가 없으면 REAL 준비를 거절하며 가짜 0이나 과거 값을 넣지 않는다.

[9/18 측정 evidence](../../../../docs/evidence/workcell_candle_0918.yaml)는 당시 기록으로 보존한다. 새 50 mm 받침대 실행 설정으로 덮어쓰거나 그대로 복사하지 않는다.
