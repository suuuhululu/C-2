## 통합 우선 설정 준비

첫 통합은 고정된 드릴의 기존 장착 오프셋을 재사용하고 양초 중심·높이를 측정해 경로 생성 입력으로 전달한다. 매번 전체 드릴 보정·편심 재측정·정밀 기울기 보정은 후속 범위다. 값마다 실측/재사용/가정/SIMULATION 여부를 구분한다. 현재 유효한 전체 TipCalibration이 없으면 모의 기록으로 로더·함수 연결부터 시험하되 REAL 측정값으로 사용하지 않는다. 새 측정값은 노홍동의 경로 생성 입력이며 `prepared_path.py`로 생성 경로를 다시 옮기는 설정을 추가하지 않는다.

## 담당과 기준 모델·실측값 분리

- 이시율: workcell·도구·이동/접촉/가공 설정과 측정 근거 작성. 노홍동은 기준 경로 모델·단위·영역을 대조하고 김세은은 로딩·검증·공정 연결을 맡는다.
- `workcell.yaml`의 기준 양초 모델을 매 작업 실측값으로 덮어쓰지 않는다. 양초 중심·축/기울기·반지름·측정 시각·유효성·잔차는 별도 불변 측정 스냅샷으로 연결한다. 정확한 저장 필드는 통합 전 합의한다.
- prepared REAL 실행은 준비 workcell의 승인된 `home.tcp_pose`와 배포 실행 프로파일의 `execution_context.entry_planning` 정책이 필요하다. 정책은 실측 `top_z_m`에 대한 TCP 상공 여유 범위, 후보 간격, 보간 간격, 원통 최소 간격, J3/J5 여유, 샘플 간 최대 관절 변화, 시작 자세 허용차와 사용할 모션 프로파일 ID를 명시한다. HMI는 이 정책을 측정 전에 읽기 전용으로 검사하고, 측정 성공 후 새 불변 스냅샷의 `workcell.entry_planning`에 복사한다. 중심·반지름·윗면·바닥은 측정값으로 덮어쓰며 두 원본 JSON은 수정하지 않는다. 310 mm 같은 과거 절대 좌표를 기본값으로 만들지 않으며, 정책이 없거나 형식이 틀리면 모션 전에 거절한다.
- 도구 장착 보정과 양초 측정 기록을 분리한다. 이시율이 전달한 실측 스냅샷을 노홍동이 3D 경로 생성 입력으로 사용한다. 공정에서 생성 경로의 중심을 다시 옮기는 단계는 두지 않는다. 기존 1점 도구 확인만으로 양초 이동과 드릴 이동을 구분할 수는 없다.
- 이미지·배치·도구/설정·실측 스냅샷·생성 경로·검사 결과를 ID·버전·해시로 묶는다. [새 공정 흐름](../README.md)의 최종 표시·검사·실행 경로가 같아야 한다.
- 목표 깊이 0.5 mm·허용오차 ±0.3 mm·최대 깊이 1.0 mm는 사용자가 제시한 검증 목표다. 실물 깊이 달성값이나 힘에서 바로 환산되는 값이 아니다. 첫 하트 실험의 모델상 깊이 0.3 mm와 구분하며 검증되지 않은 힘 적응 폭을 기본값으로 확정하지 않는다.

### 조각용 작업영역

`execution_context.engraving_workspace`는 `frame_id: c2_base`,
`waypoint_min_z_m: 0.05`를 사용한다(2026-09-23 사용자 지정).
좌표는 제어기 TCP가 아닌 도구 끝 waypoint이며 0.05 m는 허용한다.
X/Y 경계와 Z 상한은 지정하지 않는다. 측정용 `workcell.trial_scene`은 유지한다.
HMI는 이 설정을 실측 스냅샷의 `workcell.engraving_workspace`에도 복사한다.
ENTRY 보간 샘플, 본경로, 오프셋을 반영한 실행 계획에 하한 검사를 적용한다.
기존 스냅샷에 필드가 없으면 같은 0.05 m 하한을 적용한다.
이 검사는 기존 양초 간격·IK·관절 검사를 대체하지 않으며 전체 메시 충돌 검사가 아니다.
