# c2_process · 코드·담당자·통합할 공정

확인일 **2026-09-20**, GitHub main **`72618aa4c966936f47a9d80f1f0d09146b7b2739`**(PR #38 병합). main 소스, 담당자 작업 보고, 로컬 초안, 구현 예정 기능을 구분한다. 소스 존재와 HMI부터 실기까지의 통합 완료는 다르다.

이시율의 요청에 따라 **준비 확인 → 실제 양초 측정 → 실행 경로 보정 → 최종 관절 검사 → 조각**을 목표 순서로 정리한다. 김세은이 공유한 기존 PRECHECK 관절 검사 → TOOL_CHECK에서 바뀌는 **연결 변경안**이며 공통 코드·통신에는 아직 반영되지 않았다. [전체 구조](../../../docs/SYSTEM_STRUCTURE.md), [계약 v2와 변경 필요 사항](../../../docs/INTERFACE_GUIDE.md)을 함께 확인한다.

## 코드별 역할·상태

`.py`는 별도 표시가 없으면 `c2_process/` 안의 형제 모듈이다. **main 존재**는 소스 제공 가능, **담당자 보고**는 해당 작업 코드 확인 전, **로컬 초안**은 미병합, **구현 예정**은 아직 없는 기능을 뜻한다.

| 파일 | 담당자 | 역할·대표 함수 | 확인 상태 / 남은 일 |
| --- | --- | --- | --- |
| `node.py` | 김세은 | ExecuteProcess·StopProcess 수신, ProcessState·ProcessEvent 발행 | main 없음. 담당자가 부분 통합·실패·정지 시험 보고. 코드 공유 후 새 순서 연결 확인 필요 |
| `state_machine.py` | 김세은 | 준비→측정→검사→드릴 확인→실행 순서와 실패·정지 시 후속 단계 차단 | main 없음, 담당자 작업 보고. 현장 보정과 취소 가능한 드릴 ON 확인 연결 예정 |
| `preconditions.py` | 김세은 | 경로/설정·모드·연결·제어권·현재 위치·정지·고정·TCP·하중 확인, 검사 결과로 실행 허용 판단 | main 없음, 담당자 작업 보고. 처음 기본 준비 검사와 보정 후 최종 경로 검사로 구분 |

### 원래 이시율의 세 파일에서 달라지는 것

- **유지:** `robot_adapter.py`, `tool_calibration.py`, `engraving.py`. 제거하는 파일은 없다.
- **김세은 담당:** 이미 main에 있는 `joint_check.py`의 구현·보강과 검사 결과에 따른 공정 진행 판단. 이시율의 추가 업무로 배정하지 않는다.
- **추가할 기능:** 양초 측정 `workpiece_calibration.py`, 보정 후 실행 경로 생성 `prepared_path.py`. 후자는 기존 로컬 깊이 적용 코드를 확장하며 중복 변환 모듈은 만들지 않는다.
- **내부 구현 후보:** `motion_guard.py`·`moving_contact.py`는 어댑터 보조로 사용한다. 파일 수와 노드 수는 다르다.
- **범위 제외:** 자동 집기·반납·청소, `gripper_adapter.py`·`tool_sequence.py`·별도 그리퍼 노드. 실패 후 자동 홈 복귀도 기본 동작으로 넣지 않는다.

## 실행 순서와 함수/통신 경계

1. **HMI → c2_path [ROS Action `/c2/generate_path`]**: 이미지·배치·기준 설정을 보내 SVG·기준 3D 경로·미리보기·기하 검사 결과를 받는다. 현재 c2_path 서버는 SIMULATION/test_only 범위다.
2. **HMI → c2_process [ROS Action `/c2/execute_process`]**: 미리보기 확인 후 실행 요청을 보낸다. 김세은의 `node.py`가 받아 `state_machine.py`를 시작한다. 공정 main 노드는 아직 없다.
3. **state_machine → preconditions → robot_adapter [내부 함수]**: 경로/설정·연결·제어권·현재 관절/위치·정지·고정·TCP·하중·도구 보정 유효성을 확인한다. 관측에는 기존 `observe()` 등을 사용한다.
4. **state_machine → workpiece_calibration → robot_adapter [내부 함수, 신규 연결]**: 드릴 OFF 확인 후 양초를 측정한다. **측정용 접근·터치·후퇴도 움직이기 전에 검사한다.** 새 양초의 이동과 드릴 장착 변화를 같은 1점 오차만으로 구분하지 않는다. 도구 보정이 무효면 먼저 별도 장착 보정이 필요하다.
5. **state_machine → prepared_path [내부 함수, 확장 예정]**: 실측 양초에 맞춰 경로·깊이·연결 이동을 확정한다. 원본을 보존하고 새 실행 경로 버전/해시와 보정·설정 참조를 만든다. 노홍동이 그림을 다시 변환할 필요는 없다.
6. **state_machine/preconditions → `check_path_joints(final_path, adapter, tool_offset_m, ref_joints_rad, …)` [내부 함수]**: 도구 끝을 제어기 TCP로 변환해 최종 경로의 IK를 검사한다. J5뿐 아니라 전체 관절·J6 누적 회전·연결 구간·미검사 조건을 판단한다. 현재 함수만으로 모든 특이점/충돌 검증이 끝나는 것은 아니다.
7. **공정 ↔ HMI [통신 확장 합의 필요]**: 보정된 최종 경로·검사 결과를 표시하고 취소 가능한 드릴 ON 확인을 받는다. 기존 상태·이벤트/결과 통신에 연결할 필드와 운영자 확인 입력·경로 재확인 절차를 김세은·이수현이 맞춘다. 현재 구현된 통신으로 오인하지 않는다.
8. **state_machine → `execute_path(final_path, ctx, on_progress=…, adapter=adapter)` [내부 함수]**: 검사한 동일 경로를 실행한다. 이미 적용한 깊이·보정을 다시 더하지 않는다. 진행 콜백을 HMI 상태로 변환한다. 접근·이탈을 상태 기계와 조각기에서 이중 실행하지 않는다.
9. **공정 → HMI [Action 결과·`/c2/process_state` Topic·`/c2/process_events` Topic]**: 정상 이탈까지 확인해 완료를 보낸다. `/c2/stop_process` Service 접수와 실제 정지 확인은 구별한다. 실패·보호정지·통신 단절 뒤 무조건 후퇴/홈 명령을 보내지 않는다.

`go_to_path_start(path, ctx, adapter)`·`return_home(ctx, adapter)`는 김세은의 연결 요청에 등장했지만 기준 main에는 없다. 경로에 있는 접근/이탈과 중복되지 않도록 역할·호출 위치부터 합의한다. 구현된 함수로 표시하지 않는다.

## 보정·경로·검증의 한계

- **도구와 양초는 별개다.** `measure_tool_tip()`은 알려진 축/반지름으로 드릴 돌출을 구한다. 양초가 움직였다고 도구 오프셋까지 동시에 바꾸면 두 오차를 혼동한다. 신뢰할 도구 기준과 충분한 측정 방향·높이·잔차 검증이 필요하다. 한 면 접촉으로 전체 3D 축을 측정했다고 표시하지 않는다.
- **기준 중심과 현장 중심 차이 자체는 JSON 오류가 아니다.** 노홍동의 기준 모델에 이시율의 실측 변환을 적용한다. 반지름/형상까지 다르면 평행이동만으로 부족하므로 U/V·표면 법선 재매핑과 치수 정책도 검토한다.
- **불변 데이터:** 원본과 실행 경로는 각각 ID·버전·SHA-256을 갖는다. 한 `run_id`가 원본→양초/도구/설정 스냅샷→최종 경로→검사 결과를 참조한다. HMI의 최종 표시·검사·실행은 같은 최종 경로를 사용한다. 서로 다른 내용에 같은 해시를 붙이지 않는다. 로컬 객체 해시와 파일 바이트 해시도 구분한다.
- **깊이:** 표면 실측+명시 깊이가 기준이고 힘은 접촉·이상 감시 자료다. 힘만으로 실제 홈 깊이를 확정하거나 힘 부족 때 무제한 진입하지 않는다. 가공 중 깊이 조절은 허용 범위의 관절·이동 검사 이후에만 통합한다.
- **실기 근거:** 9/20 별도 시험 실행기로 첫 하트를 실행했고 사용자가 전체가 이어져 새겨졌다고 확인했다. 당시 모델상 깊이는 0.3 mm다. main 상태 기계 통합·반복 중심 측정·실제 0.5±0.3 mm 깊이 달성의 증거는 아니며 물리적 깊이는 미측정이다.
- **샘플:** 최신 `heart_seam`은 이음매의 `ANGLE_OUT_OF_RANGE` 거절 시험이다. 정상 조각 도안으로 실행하지 않는다. `heart_pair`는 반대 면으로 가는 추가 연결 모션까지 검사해야 한다.

## 다음 구현 순서

1. 김세은·이시율: 함수 인자·`StepResult`·취소/정지/후퇴 조건과 새 호출 순서를 맞춘다. `SUCCEEDED/FAILED/STOPPED/UNKNOWN`을 구별한다.
2. 이시율: 실험용 측정·경로 준비·동작 판정을 공통 모듈로 이관하고, 보정된 최종 경로와 도구 오프셋·필요한 설정을 김세은의 검사 함수에 전달한다. 검사된 경로를 그대로 실행하도록 보장한다.
