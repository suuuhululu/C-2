# Dart Platform 로컬 설치 위치

강사 예시의 설치 위치를 유지하기 위한 안내다. 편집용 Mac에는 설치하지 않았고, C-2에는 설치 파일을 배포하지 않는다. 사용자·팀원이 보고한 가상 로봇 이동만으로 특정 Dart Platform 설치·버전까지 확인된 것으로 취급하지 않는다.

실제 설치 프로그램은 이 폴더 아래에 로컬로 준비하고, 실행 후 생기는 `Logs/`도 이곳에 둔다. 이 README를 제외한 내용은 Git에서 제외하므로 팀원이 clone만 해서 프로그램을 사용할 수 있는 것은 아니다.

팀은 설치 파일을 복사해 배포하는 대신 공식 배포 위치·설치 버전·OS·실행 절차를 [의존성 기록](../../docs/DEPENDENCIES.md)에 남긴다.

설치 문서를 이 폴더에 더 추가하려면 `.gitignore` 예외도 함께 검토한다.
