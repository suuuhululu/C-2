## 1. 선택 결과와 적용 범위

보고서는 **제공된 네 도안의 기본 변환기로 Potrace 1.16을 선택**했다. 입력별로 배경을 분리해 이진 마스크를 만든 뒤 작은 요소 자동 삭제를 끄고 다음 설정을 적용했다.

| 옵션 | 선정값 |
|---|---|
| `turdsize` | `0` |
| `alphamax` | `0.85` |
| `opttolerance` | `0.1` |
| `turnpolicy` | `black` |
| `unit` | `100` |
| 입력 확대 | 없음 |

선정 이유는 큰 꽃잎·원형 띠의 매끄러움과 잉크 영역의 굵기·채움 표현을 함께 고려했기 때문이다. RDP와 해당 보고서의 베지어 구현은 픽셀 마스크 일치율이 더 높았지만 작은 꺾임·물결 형태가 남았다고 평가했다. 이 시각 판단은 원문 작성자의 평가이며, 이번 문서 정리에서 확대 그림 파일을 다시 검사한 결과는 아니다.

**독립 요소 140개가 대응됐지만 내부 빈 영역은 263개 중 254개만 기준을 만족했다.** 나머지 9곳은 검토 대상으로 남는다. 네 도안·단색 잉크·시험한 설정에 대한 선택이며 모든 이미지의 최적 방식이나 완전 복원을 입증하지 않는다.

## 2. 기존 경로 검증과의 차이

| 구분 | 기존 검증 | 이번 독립 실험 |
|---|---|---|
| 목적 | 중심선을 정리하고 이동 좌표·작업 순서를 개선 | 원본의 선 굵기·채움·작은 무늬를 SVG 영역으로 표현 |
| 표현 | 중심선·작업선·이동 좌표 | 채워진 도형과 내부 구멍 |
| 비교 지표 | 작업선 수·좌표 수·전개도 비가공 이동 | 마스크 겹침·독립 요소/빈 영역 대응·SVG 크기 |
| 이번에 검증하지 않은 것 | 기존 보고서의 한계 참조 | 가공 경로·깊이·힘·속도·3D 변환·로봇 동작 |

Schneider 원리의 베지어 후보는 기존 프로젝트 소스의 재실행이 아닌 별도 Python 구현이다. 기존의 작업선 73.36%·좌표 12.39%·이동 70.30% 감소를 Potrace의 효과로 옮겨 적지 않는다. 이번 SVG는 후속 가공 설계의 입력이며 로봇 실행 프로그램이 아니다.

## 3. 입력과 비교 조건

| 도안 | 크기 | 특징 | 공통 전처리 |
|---|---:|---|---|
| 꽃 테두리 | 236×456px | 가는 선·꽃잎·잎맥·작은 점 | 회색조 Otsu 이진화 |
| 종이 위 꽃 | 236×446px | 종이 배경·흐린 선·밀집 줄기 | 25×25 배경 추정으로 밝기 보정 후 Otsu |
| 원형 장식 | 450×450px | 굵은 띠·채워진 장식·작은 구멍 | 파란 잉크의 색상·채도 분리 |
| 새 반복 무늬 | 554×554px | 내부 흰 부분·교차·회색 배경 무늬 | 파란 잉크의 색상·채도 분리 |

사용자 이미지 4번과 5번은 RGB 픽셀이 같아 하나로 취급한 기록이다. JPEG Q60과 가로·세로 50% 입력은 네 원본에서 만든 열화 자료이며 독립적인 추가 도안이 아니다. 색상·채도 차이를 그대로 복원하는 컬러 벡터화 실험도 아니다.

각 도안의 후보들은 같은 전경 마스크, 즉 도안으로 분리한 픽셀 영역을 입력받았다. 공통 전처리에서 전경 구멍 채우기·가지 삭제를 하지 않았다. 종이 배경 추정에 사용한 닫힘 연산과 전경 구멍 메우기를 구분한다.

| 후보 | 구현·조건 |
|---|---|
| 윤곽 + RDP | scikit-image marching squares + Douglas–Peucker, 전경 8연결, 허용 거리 0.5px |
| 윤곽 + Schneider 베지어 | 같은 윤곽에 독립 Python 구현, 허용 거리 0.5px, 최소제곱·최대 4회 재매개화·재귀 분할 |
| Potrace 최초 시험 설정 | Potrace 1.16, `alphamax=1`, `opttolerance=0.2`, `turdsize=0`, `turnpolicy=minority`, `unit=100` |
| VTracer | Python 패키지 0.6.12, binary/spline, speckle=0, corner=60, length=4, splice=45 |

중심선만으로는 폭·면적을 직접 유지하지 못하므로 Zhang–Suen 중심선 방식은 이번 주 비교에서 제외했다. RDP와 베지어도 영역의 외곽과 내부 구멍에 적용했다.

시험 기록은 기본 비교 48건(4도안×4후보×3입력 조건), Potrace 민감도 16건, 합성 도안 7건, 선정 설정의 열화 입력 추가 변환 8건이다. 재실행·파생 입력을 포함하므로 **79개의 독립 표본이 아니다**. 별도 독립 검증 세트는 확보하지 않았다.

SVG는 librsvg 2.58.0으로 가로·세로 4배 렌더링하고 원래 픽셀 크기로 점유율을 평균한 뒤 0.5 이상을 전경으로 정했다. 실제 도안의 정답 SVG가 없어 전경 마스크를 비교 기준으로 사용했다. 이 마스크 자체의 임계값·잡음·끊김이 결과에 영향을 줄 수 있다.

## 4. 원본 네 도안의 보고 수치

| 후보 | 평균 마스크 IoU | 독립 요소 대응 | 빈 영역 대응 | SVG 4개 합계 |
|---|---:|---:|---:|---:|
| 윤곽 + RDP | 95.97% | 136/140 | 259/263 | 287.1 KiB |
| 윤곽 + Schneider 베지어 | 96.50% | 139/140 | 252/263 | 640.7 KiB |
| Potrace 최초 시험 설정 | 88.50% | 137/140 | 245/263 | 140.1 KiB |
| VTracer 0.6.12 | 76.89% | 123/140 | 148/263 | 264.4 KiB |
| **Potrace 선정 설정** | **89.24%** | **140/140** | **254/263** | **161.4 KiB** |

- 영역 겹침 비율 **IoU(Intersection over Union)**는 교집합/합집합이다. 표의 평균은 도안별 단순 평균이며 이미지 면적 가중 평균이 아니다.
- 독립 요소는 전경 8연결 성분, 빈 영역은 배경 4연결 내부 구멍이다. 면적 4px 이상인 기준 요소에 대해 위치가 대응하고 IoU가 0.5 이상인지 평가했다.
- 선정 결과의 독립 요소는 같은 출력 성분에 중복 대응하지 않는지도 확인했다고 기록돼 있다. 정확한 선 끝·분기·교차·선폭 전체의 보존을 뜻하지 않는다.
- 4px 미만 요소를 평가에서 제외한 것이 삭제를 허용한다는 의미는 아니다. 의미 있는 장식과 잡음을 자동 구분한 결과도 아니다.
- 선정 설정의 평균 전경 면적 비율은 **101.74%**다. 전체 면적이 비슷해도 국소 선폭은 달라질 수 있다.
- SVG 용량은 직렬화 형식을 포함한다. 로봇 경로 수·가공 시간·복원 정확도로 해석하지 않는다.

### 선정 설정의 도안별 결과

| 도안 | 마스크 IoU | 독립 요소 대응 | 빈 영역 대응 | 전경 면적 비율 |
|---|---:|---:|---:|---:|
| 꽃 테두리 | 81.33% | 2/2 | 107/112 | 104.92% |
| 종이 위 꽃 | 87.82% | 3/3 | 92/94 | 103.51% |
| 원형 장식 | 94.63% | 110/110 | 20/20 | 98.16% |
| 새 반복 무늬 | 93.19% | 25/25 | 35/37 | 100.39% |

빈 영역 기준 미달 9곳은 꽃 테두리 5곳·종이 위 꽃 2곳·새 반복 무늬 2곳이다. 완전 삭제뿐 아니라 변형·합침 때문에 대응 기준을 만족하지 못한 경우도 포함된다. 원문은 검토 위치를 표시했다고 설명하지만 해당 좌표·그림 파일은 이번 PR에 포함하지 않았다.

## 5. 민감도·합성 도안 결과의 해석

- `alphamax=0.65`, `opttolerance=0.1`, `turnpolicy=black`은 세부 대응이 개선되는 대신 원형 점 등이 각져 보이는 경우가 기록됐다. 선정 설정 `alphamax=0.85`는 세부 보존과 큰 곡선의 매끄러움을 절충한 판단이다.
- 최근접 2배 확대 후 Potrace 설정(`alphamax=1`, `opttolerance=0.1`, `turnpolicy=black`)은 원본 네 도안에서 평균 IoU **99.96%**, 평가한 빈 영역 전체 대응을 보였다. 미세 계단이 남는다는 시각 판단으로 기본값 대신 보수적인 형태 보관 대안으로 남겼다.
- 여러 옵션이 함께 달라졌으므로 개선을 `alphamax` 하나의 효과로 단정하지 않는다.
- 합성 기준 SVG 시험에서는 2배 확대 Potrace가 IoU **90.24%**, 원형 띠 경계의 평균 반지름 오차 **0.162px**로 가장 좋았다. 선정 설정은 **86.42%**, **0.229px**였다. 기본 선택이 모든 정량 지표에서 1위라는 결론은 아니다.
- 합성 도안은 128×128 기준 SVG를 8배 렌더링 후 축소한 통제 입력이다. 실제 도안 네 종의 예술적 정답을 대신하지 않는다.

| 선정 설정의 IoU | 원본 PNG | JPEG Q60 | 가로·세로 50% |
|---|---:|---:|---:|
| 꽃 테두리 | 81.33% | 81.15% | 82.57% |
| 종이 위 꽃 | 87.82% | 88.73% | 86.18% |
| 원형 장식 | 94.63% | 94.90% | 91.14% |
| 새 반복 무늬 | 93.19% | 92.85% | 88.45% |

각 열은 해당 입력에서 만든 서로 다른 마스크와 비교했다. 값이 높아졌다고 원본 복원이 좋아진 것은 아니다. 원본 마스크로 환산한 보조 비교는 원문의 `metrics.csv`에 기록됐다고 설명돼 있으며 이번 PR에서는 해당 CSV를 확보하지 않았다. 처리 시간은 단일 실행·입출력·외부 프로세스 비용을 포함해 정식 속도 순위로 사용하지 않았다.

## 6. 실제 크기 SVG와 후속 가공 연결

지름 70mm·높이 200mm를 기준으로 전개도 **219.911485751×200mm**에 원본 이미지 전체를 같은 가로·세로 배율로 맞추고 중앙 배치했다. 별도 여백·자동 반복 무늬는 추가하지 않았다.

| 도안 | 배치된 이미지 크기 |
|---|---:|
| 꽃 테두리 | 103.51×200.00mm |
| 종이 위 꽃 | 105.83×200.00mm |
| 원형 장식 | 200.00×200.00mm |
| 새 반복 무늬 | 200.00×200.00mm |

출력 SVG는 2D 영역 표현이다. 후속 단계에서는 윤곽 가공·중심선 가공·영역 내부 가공 중 어떤 방식으로 굵기·채움을 실물에 표현할지 정해야 한다. 이 보고서는 다중 가공선·깊이·공구 형상·진입/이탈·3D 자세를 확정하지 않았다. 여백 없이 배치한 전개도 전체를 실제 로봇이 가공할 수 있다는 뜻도 아니다.

## 7. 공유한 근거와 재현 범위

이번 PR에는 이 요약 문서와 [보고서 출처·전사 수치 JSON](evidence/svg_vectorization_report2.json)을 추가했다. JSON은 첨부 Markdown에서 옮긴 값이며 실험 프로그램이 생성한 원본 지표 파일은 아니다. 첨부 보고서의 SHA-256을 기록해 참고한 버전을 식별한다. 임시 서명된 파일 다운로드 주소는 공유 문서에 저장하지 않는다.

원문에는 `selected/`, `results/`, `metrics.csv`, `selected_metrics.json`, `sensitivity.json`, `synthetic.json`, `review_hotspots.json`, 실험 스크립트와 `manifest.json`이 산출물로 기재돼 있다. 이번 문서 작업에서는 해당 원본 이미지·SVG·그림·스크립트·환경을 가져오거나 재실행하지 않았다. **C-2 clone만으로 이 비교 실험을 재현할 수 있는 상태는 아니다.**

후속 공유 시 입력 해시·버전·마스크 생성 조건·원본 지표·검토 지점·선정 SVG를 함께 연결한다. 원문이 인용한 알고리즘 자료는 [Potrace 매뉴얼](https://potrace.sourceforge.net/potrace.1.html), [scikit-image 0.24](https://scikit-image.org/docs/0.24.x/api/skimage.measure.html), [Schneider 원본](https://github.com/erich666/GraphicsGems/blob/master/gems/FitCurves.c), [VTracer 0.6.12](https://pypi.org/project/vtracer/0.6.12/)이다. 이 문서는 해당 자료를 새로 전부 검증한 보고서가 아니라 9/17 팀 실험 기록의 정리다.
