# 현장 설정과 실행 초안의 확인 범위

기준일: 2026-09-17. 사용자 제공 정보와 오프라인 기록을 정리했으며 장비를 직접 조회·구동한 결과가 아니다. 실제 장비 주소와 실행 좌표는 실행 PC의 로컬 설정에서 관리한다.

| 항목 | 확인 내용 | 추가 확인 |
|---|---|---|
| 로봇·ROS | M0609, 프로젝트 기준 ROS 2 Jazzy | 실행 PC의 설치본·제어기 호환성 |
| 브링업 | 사용자 지정 `m0609_rg2_bringup`의 `bringup.launch.py`, real 모드, m0609 모델 | 편집 Mac에서는 해당 패키지 미발견. 실제 PC에서 패키지·서비스 확인 |
| TCP | 등록 이름 `GripperDA_v3`, 사용자가 헤라 끝까지 보정된 TCP임을 확인 | 헤라 재파지 후 반복성, 빈 그리퍼 상태의 별도 TCP |
| 하중 | 화면에서 `ToolWeight_1` 등록 프로필 확인 | 현재 공구 조합과의 일치, 빈 그리퍼 프로필. 미확인 관성값을 임의 생성하지 않음 |
| 홈 | 사용자가 6개 관절각과 MoveJoint 요청을 제공 | 현장 경유 경로. 홈 각도만으로 충돌 없는 복귀가 보장되지 않음 |
| 작업대 | 평평하게 배치 가능, 높이 60mm라는 사용자 정보 | 로봇 베이스 기준 표면 높이가 60mm라는 뜻은 아님 |
| 대상 원기둥 | 현재 목표 지름 70mm·높이 200mm | 실제 중심축·고정 지그·치수 오차·변형 |
| 헤라 | 끝이 송곳처럼 가는 공구 | 홈 폭·깊이·속도·각도·양방향 가공 품질 |
| 세척 패드 | 두께 20mm 스펀지를 작업대 둘레에 설치하는 구상 | 표면 위치·고정·찢김·재부착·재료별 주기 |
| 그리퍼 | 2점 그리퍼, 사용자 브링업 이름에 RG2 포함 | 이름만으로 실제 모델·배선·제어·피드백을 확정하지 않음 |
| 버전 | 제공 화면에 DART-Platform GV02120100 표기 | 앱 제목을 제어기 펌웨어 버전으로 간주하지 않음 |

## 평면용 실행 초안

개인 작업 폴더에 장식 도안용 평면 DRL 생성 초안, ROS 2 전송 도구와 읽기 전용 설정 확인 도구가 있다. 이번 업데이트에는 문서와 [확인 결과 요약](evidence/planar_draft_validation_summary.json)만 공유한다.

- 대상 데이터: 작업선 1,140개, 좌표 14,857개. 원본 좌표 보존 여부를 오프라인 확인했다.
- 기본 실행 비활성화와 설정 누락 시 모션을 호출하지 않는 조건을 Python 대체 실행으로 확인했다.
- 현장 원점·자세·깊이·속도·이탈 거리 등이 미정이므로 실행 준비 완료 상태가 아니다.
- native DRL, 실제 ROS 서비스 호출, 제어기 연결·로봇 이동은 검증하지 않았다.
- 원기둥의 자세·공중 이동, 자동 공구 파지·반납, 스펀지 세척, 자동 치수 확인은 이 평면 초안의 구현 완료 기능이 아니다.
- `DrlStart` 요청 수락과 전체 작업 완료를 구분한다. 통신 결과가 불명확할 때 동일 명령을 자동 재전송하지 않는 구조로 설계한다.

관련 설계는 [서비스 흐름](SERVICE_FLOW.md), [시스템 아키텍처](SYSTEM_ARCHITECTURE.md)를 따른다. 로봇·외부 패키지의 PC별 설치 이력은 [공통 의존성 문서](../../docs/DEPENDENCIES.md)에 구분한다.
