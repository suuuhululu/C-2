## 0917 단위 실기·측정 기능 추가 기록

Notion의 [1차 검증](https://app.notion.com/p/1-7e05211811398358922701bfaacfb585)에는 지점토·송곳으로 정사각형·원·별을 시연하고 지점토 뭉침을 관찰한 기록이 있다. 사용자는 선분 그리기 구현도 보고했다. 이는 기존 평면 DRL 초안의 실기 실행을 확인한 기록과는 구분한다. 시험한 코드·커밋·실행 환경을 연결한 자료는 아직 필요하다.

[시율의 사전 작업 자동화](https://app.notion.com/p/3de521181139806b850ec21bf6e0ee3a)에서는 닫힌 그리퍼로 윗면·네 옆면·받침대를 탐색하는 노드1의 코드와 흐름을 읽었다. TCP 명령 좌표와 그리퍼 접촉점 기록 좌표를 구분하며, 방향별 보정을 포함한다. 공통 모듈·실제 bag를 확보하지 않아 접촉 판정과 수정 후 반복성 검증을 완료했다고 판단하지 않는다.

- 평면 시연의 `z축 45.5mm` 메모, 다른 툴 축 방향 길이 메모와 노드1의 접촉점 보정은 하나의 확정 TCP로 합치지 않는다. 공구 장착 상태·프로필·전체 위치와 자세를 시험별로 대조한다.
- 사람이 송곳을 전달한 뒤 그리퍼를 조작하는 기능은 자동 취출·반납과 구분한다. 송곳 끝 길이 측정·SVG 크기 맞춤은 코드·결과·완료 조건을 추가로 연결한다.
- 세은의 원통 변환 문서 예시에는 반지름 37.5mm·높이 200mm가 사용됐다. 현재 목표 지름 70mm 시험편에 그대로 적용한 결과로 기록하지 않는다.
- 홈 폭·깊이·형상 오차·반복 횟수와 실제 가공 속도 조건은 아직 시험 기록으로 보완해야 한다.

상세한 수행 보고·코드 확인·미확인 항목은 [0917 개발 일지](daily/2026-09-17.md)에 모았다. 아래 평면 DRL 초안의 미실행 상태는 이 단위 시연 보고 때문에 자동으로 변경하지 않는다.

## 평면용 실행 초안

개인 작업 폴더에 장식 도안용 평면 DRL 생성 초안, ROS 2 전송 도구와 읽기 전용 설정 확인 도구가 있다. 이번 업데이트에는 문서와 [확인 결과 요약](evidence/planar_draft_validation_summary.json)만 공유한다.

- 대상 데이터: 작업선 1,140개, 좌표 14,857개. 원본 좌표 보존 여부를 오프라인 확인했다.
- 기본 실행 비활성화와 설정 누락 시 모션을 호출하지 않는 조건을 Python 대체 실행으로 확인했다.
- 현장 원점·자세·깊이·속도·이탈 거리 등이 미정이므로 실행 준비 완료 상태가 아니다.
- native DRL, 실제 ROS 서비스 호출, 제어기 연결·로봇 이동은 검증하지 않았다.
- 원기둥의 자세·공중 이동, 자동 공구 파지·반납, 스펀지 세척, 자동 치수 확인은 이 평면 초안의 구현 완료 기능이 아니다.
- `DrlStart` 요청 수락과 전체 작업 완료를 구분한다. 통신 결과가 불명확할 때 동일 명령을 자동 재전송하지 않는 구조로 설계한다.

현재 코드의 흐름과 노드 책임은 [인터페이스 안내](INTERFACE_GUIDE.md), [시스템 구조](SYSTEM_STRUCTURE.md)를 따른다. 로봇·외부 패키지의 PC별 설치 이력은 [공통 의존성 문서](../../docs/DEPENDENCIES.md)에 구분한다.
