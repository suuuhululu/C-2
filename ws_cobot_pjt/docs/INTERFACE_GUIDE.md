# 시스템 모니터·좌표 생성·고정 드릴 공정 인터페이스 안내

**2026-09-21**, main `19ef4c6` 확인. [디렉토리·담당](SYSTEM_STRUCTURE.md), [공정 파일·함수·상태](../ws_cobot1/src/c2_process/README.md), [배포된 상세 계약 v2](INTERFACE_RECOMMENDATION.md)를 구분해 읽는다.

## 현재 코드와 이번 변경 범위

HMI·서버·공통 타입, c2_path 계산·GeneratePath Action 서버, c2_process 어댑터·도구 보정·관절 검사·조각 소스가 main에 있다. HMI↔c2_path의 관리 파일·미리보기 부분 통합과 SIM 스냅샷/ZIP 교환 화면도 존재한다. c2_path는 SIMULATION/test_only이며 공정 ROS 노드·패키지 설정은 main에 없다. 김세은의 부분 통합·실패·정지 시험 보고는 담당자 작업 현황으로 구별한다. 전체 실기 통합 완료로 표시하지 않는다.

이번 변경은 **역할·구현 상태와 새 호출 순서의 문서화**다. ROS 타입·서버·HMI 코드를 수정하지 않으며 schema_version은 2 그대로다. 아래 새 흐름을 v2 클라이언트가 이미 지원한다고 해석하지 않는다.

## 유지하는 통신 경계

| 통신 | 형식 | 담당 간 연결 |
| --- | --- | --- |
| `/c2/generate_path` | GeneratePath Action | 이수현 HMI/서버 ↔ 노홍동 좌표 노드 |
| `/c2/execute_process` | ExecuteProcess Action | 이수현 HMI/서버 ↔ 김세은 공정 노드 |
| `/c2/stop_process` | StopProcess Service | HMI/서버 → 공정, 정지 접수 응답 |
| `/c2/process_state` | ProcessState Topic | 공정 → HMI, 현재 상태 |
| `/c2/process_events` | ProcessEvent Topic | 공정 → HMI, 사건 기록 |

김세은의 공정 모듈과 이시율의 보정·모션 모듈은 **같은 공정 노드 안의 Python 함수 호출**로 연결한다. 이시율 모듈에서 어댑터를 호출하면 어댑터가 공급자 드라이버와 통신한다. 파일 담당자가 다르다는 이유로 중간 ROS Topic이나 별도 보정 노드를 만들지 않는다.

## 순서 변경안과 기존 v2의 차이

**목표 순서:** HMI 측정 요청→준비 확인→양초 실측→실측 스냅샷으로 3D 경로 생성→미리보기 확인→조각 요청→최종 관절 검사→드릴 ON 확인→조각·이탈→완료.

| 항목 | 기존 v2 / 기존 구현 | 이번 통합 목표 |
| --- | --- | --- |
| 도구 장착 보정 | 3점 도구 보정·불변 설정 준비 | 기능은 유지. 철사 고정 상태에서는 기존 장착 기준 재사용, 매번 전체 재보정은 첫 통합에서 제외 |
| 양초 측정 시작 | 경로 없는 측정 요청 계약 없음 | HMI 작업 준비 요청을 공정에서 받아 기본 준비·측정용 이동 검사 후 측정 |
| 3D 경로 생성 | c2_path의 고정 test_only 모델 상수 사용 | 이시율의 실측 스냅샷을 입력받아 노홍동이 위치·자세·경로 생성 |
| 미리보기 | 기준 모델의 생성 경로 | 실측값으로 생성한 경로. 확인 후 ExecuteProcess 요청 |
| 관절 검사 | 공정 PRECHECK 검사 계획 | 측정/도구 설정 유효성을 다시 확인한 뒤 깊이·접근/이탈을 포함한 최종 경로 검사 |
| 드릴 전원 | 별도 취소 가능한 확인 입력 미정 | 측정 OFF, 조각 직전 ON 운영자 확인 대기·취소 지원 |

이전의 “기준 3D 경로 생성 후 이시율의 prepared_path에서 중심·기울기를 다시 보정”하는 안은 채택하지 않는다. **측정 기능은 workpiece_calibration.py로 유지하고 측정값을 경로 생성 전에 전달한다.** 이미지→SVG→2D는 실측과 독립적으로 먼저 계산할 수 있다.

**역할 연결: 이시율 측정 → 실측 좌표 전달 → 노홍동 경로 생성 → 김세은 관절 검사 → 이시율 조각.** `workpiece_calibration.py`는 그대로 필요한 신규 모듈이고, `prepared_path.py`의 경로 재이동은 새 흐름에 넣지 않는다.

첫 통합은 수직 원통 가정을 명시하고 중심·높이 측정과 모의 입력/함수 연결부터 진행한다. 정밀 기울기·테이퍼·매번 전체 드릴 보정은 후속으로 미룬다. 현재 위치·측정용 이동 검사·최종 관절 검사·정지 처리는 유지한다. 상세 구현 범위는 [공정 README](../ws_cobot1/src/c2_process/README.md#1차-통합-범위)를 따른다.

## 연결 전에 합의할 계약

2026-09-21 사용자 변경: 양초 상하 **각 10mm 제외**가 앞선 각 20mm 제외를 대체한다.
H=150mm일 때 윗면 아래 v=10~140mm이며 기존 바닥 기준 V에는 `V=H-v`로 변환한다.
HMI의 합의 기준 표시와 현재 c2_path의 85~130mm 고정 검사는 구분한다.
[표시·좌표 기준과 미반영 범위](HMI_WORK_AREA.md)를 따른다. 이 변경만으로 실측/관절 검증이나
공통 ROS 타입 변경이 완료된 것은 아니다.

1. **준비 요청·결과:** 기존 ExecuteProcess는 경로 ID·버전·해시를 요구하므로 경로 생성 전 양초 측정을 그대로 시작시킬 수 없다. HMI→공정 측정 요청, 취소/정지, 측정 결과→HMI/서버 전달 방식을 김세은·이수현이 정의한다. 로봇 모션은 공정 하나가 소유한다. 임의 새 Action 이름이나 가짜 경로 ID를 만들지 않는다.
2. **측정 스냅샷:** 중심·높이 기준·반지름·축/0° 방향, m·좌표계·측정 시각·잔차·유효성·도구 보정 참조를 기록한다. 측정/등록/추정/미측정을 구별하며 기울기 미측정을 수직 실측 성공으로 표시하지 않는다. 정확한 키와 유효 조건은 공동 합의한다.
3. **GeneratePath 연결:** 서버가 실측 설정을 등록하고 기존 `profile_snapshot_id`·`profile_sha256`로 요청한다. c2_path는 상수 일치 검사를 실측 모델·허용 범위 검사로 바꾸되, 설정 ID·해시 일치·모드·도구 계약 검사는 유지한다. 범위 숫자는 임의 확정하지 않는다.
4. **경로·깊이 동일성:** 측정 세션→스냅샷→이미지/배치→경로→실행·검사 결과를 연결한다. 깊이 적용 주체는 한 곳으로 정하고 최종 미리보기·관절 검사 이전에 반영한다. `prepared_path.py` 이관은 필수 조건이 아니다. HMI 표시·검사·실행은 같은 최종 경로·설정을 사용한다.
5. **상태·확인:** 준비/측정/생성/미리보기/조각 요청 상태와 드릴 ON 확인·취소 입력을 맞춘다. v2에 새 단계가 이미 구현된 것은 아니다. 측정 이후 양초·도구가 바뀌거나 측정이 무효가 되면 재측정·재생성·재확인한다.
6. **함수 반환:** 이시율은 측정 결과·도구/가공 설정·실행 결과·취소/힘 초과/보호정지/시간 초과별 정지·후퇴 상태를 제공한다. 노홍동은 실측값으로 생성한 경로를 제공한다. 김세은은 `joint_check.py`를 구현·보강하고 실패/정지/미확인 뒤 조각·홈 진입을 차단한다.
7. **버전 전환:** 합의 후 타입·필드·의미의 호환성을 판단하고 문서·c2_interfaces·송수신자·시험을 함께 갱신한다. 이번 문서에서는 schema_version이나 REAL/test_only 제한을 바꾸지 않는다.

## 단위·관측·운영

- 도구 끝 경로는 `c2_base`, m·quaternion xyzw, 관절 rad. 제어기 TCP는 `GripperDA_v1`, 도구는 `engraving_drill`. 변환은 robot_adapter 한 곳에서 수행한다.
- 관측은 출처·단위·좌표계·측정 시각·유효성을 포함한다. 통신 heartbeat가 살아 있어도 오래된 측정값을 유효하게 바꾸지 않는다.
- 공정 준비는 로봇 현재 위치부터 확인한다. 도구 보정 유효성과 양초 위치를 구별하고 측정 접근/후퇴도 사전 검사한다.
- 철사 고정 중 그리퍼 열기·자동 집기·반납·청소는 제외한다. 실패나 정지 미확인 뒤 자동 이동을 추가하지 않는다.
- 가공 중 힘은 접촉·이상 감시에 활용한다. 실제 홈 깊이·실물 품질의 직접 측정값으로 표시하지 않는다.
