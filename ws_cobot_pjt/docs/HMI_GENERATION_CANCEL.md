# 경로 생성 취소·새로고침 복원

2026-09-21. 기준 main `19ef4c6` 이후 작업 브랜치 구현. 로봇 실행 정지가 아닌 이미지 경로 계산 취소 기능이다.

## 사용법

1. 이미지를 첨부하고 **경로 생성**을 누른다.
2. 작업 준비 화면 위쪽에 서버의 요청 ID·진행 단계·진행률이 표시된다.
3. 중단하려면 **경로 생성 취소**를 누른다. **취소 확인 중**에는 새 생성을 시작하지 않는다.
4. **경로 생성 취소 완료**가 표시되면 새 이미지를 넣거나 배치를 바꾸어 다시 생성한다.
5. 계산 중 브라우저를 새로고침하거나 다른 창에서 열어도 서버 상태와 취소 버튼이 복원된다.
   새로고침 자체는 계산 취소가 아니다. 이전 이미지·배치·성공 미리보기는 자동 복원하지 않는다.

120초 생성 기한을 초과하면 서버가 취소를 요청하고 계산 종료를 확인한다.
**생성 중단 미확인**이면 새 생성을 막는다. 실행 터미널에서 Ctrl+C로 실행기를 종료하고
경로 노드와 모니터를 함께 다시 시작한다. 기록·DB를 삭제할 필요는 없다.
저장 확정과 취소가 경합해 이미 생성이 완료됐다면 성공 결과를 유지한다.
상단의 공정 **정지 요청**은 이 기능과 별개이며 경로 계산 취소에 사용하지 않는다.

## 업데이트 반영

기존 실행기를 Ctrl+C로 종료한 뒤 같은 checkout에서 실행한다.

```bash
cd /home/rokey/cobot1
source /opt/ros/jazzy/setup.bash
cd ws_cobot_pjt/ws_cobot1
colcon build --packages-select c2_interfaces c2_path --symlink-install
source install/local_setup.bash
cd ../frontend
pnpm build
cd ../..
python3 ws_cobot_pjt/run_monitor.py --transport ros
```

8010 정적 화면은 새 빌드 후 브라우저 강력 새로고침(Ctrl+Shift+R)이 필요하다.
5174 개발 화면도 열려 있던 요청을 복원하도록 새로고침한다.
기존 프로세스는 소스 변경만으로 갱신되지 않으므로 경로 노드·백엔드 재시작이 필요하다.

## 계약과 구현 범위

- `/c2/generate_path`의 표준 ROS Action 취소를 사용한다. `c2_interfaces`·Goal/Result/Feedback·schema_version=2는 그대로다.
- `CANCELED`·`TIMEOUT`·`COMMUNICATION_LOST` 기존 오류를 사용한다. 실패 경로는 HMI 실행 경로로 등록하지 않는다.
- HMI 내부 HTTP에 `POST /api/operator/path-generations/{request_id}/cancel`을 추가한다.
  202는 취소 접수이며 종료 확인이 아니다. 같은 요청 취소 재전송은 기존 상태/결과를 반환한다.
- 기존 snapshot의 `generation`에 진행 또는 최근 최종 요청을 전달한다.
  HMI 상태 `CANCELING`·`UNKNOWN`은 화면/게이트웨이 내부 상태이며 ROS 공정 상태 enum을 변경하지 않는다.
- `UNKNOWN`은 중단 미확인이고 새로운 생성을 차단한다. 자동 재시작하지 않는다.
- 계산은 c2_path 내부 자식 프로세스에서 수행한다. 부모가 취소·기한을 감시하고 자식을 종료·회수한다.
  산출물은 자식에서 메모리에만 보관하고, 종료 및 마지막 취소 확인 후 부모가 원자적으로 저장한다.
  따라서 취소된 자식이 뒤늦게 성공 파일을 등록하지 않는다. 자식 임시 이미지도 정리한다.
- MOCK도 취소를 지원하되 이미 파일 저장을 시작했다면 저장 완료 결과를 기다린다.
- 전체면 HMI 배치와 별개로 c2_path의 기존 높이·각도 매핑 제한은 이번 변경에 포함하지 않는다.

공통 ROS 타입·경로/프로파일 파일 계약의 전환은 없다. HMI 화면·백엔드와 c2_path 구현을 함께
업데이트한다. 구버전 경로 노드는 긴 계산을 취소하지 못할 수 있으며 이때 중단 미확인으로 남는다.
