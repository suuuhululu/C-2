```bash
python3 -m unittest discover -s test -v
python3 build_samples.py
```

## 한계와 인계

- **ROS 빌드 미검증**: `package.xml`/`setup.py`/`setup.cfg`는 선례(`c2_interfaces`) 형식을 참고해 작성했지만, 이 세션에서 실제로 `colcon build`를 돌려보지 못했다. 팀 Jazzy 환경에서 첫 빌드 확인이 필요하다.
- **반지름 미확정**: 34mm(자로 잰 값)를 test_only로 쓴다. 독립 반지름 측정 근거가 없다 — README "미확정값" 참고.
- **이음매 각도 미확정**: 이 PR은 ±180°를 가정한다. 병합된 `workcell_candle_0919.yaml`(PR #32)은 아직 `seam_angle_deg: 0`으로, 이 PR의 가정과 다르다. 팀 확정 후 `workcell.SEAM_ANGLE_DEG`와 yaml을 함께 갱신해야 한다.
- **J5/J6**: 이 패키지는 검사하지 않는다. `joint_check.check_path_joints`(PR #34)에 위임하며, 모의 IK로만 확인했다. 실제 제어기 ikin 결과는 별도 확인 필요.
- **node.py 미구현**: GeneratePath Action 서버가 없어 이 PR만으로는 실제 요청을 받을 수 없다.
- **AI 검증 한계**: 이 표의 "통과"는 순수 Python 단위 시험과 다른 PR 소스코드를 이 세션에서 그대로 실행해 본 결과이며, 로봇·ROS·실기 검증을 대신하지 않는다. 팀원의 실제 검토·Jazzy 빌드·실기 확인이 필요하다.
