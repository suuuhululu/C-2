# 9/18 양초 실측 기록의 적용 범위

이 폴더의 [상태 JSON](clay_state_0918_candle.json)과 [workcell 후보 YAML](workcell_candle_0918.yaml)은 PR #20의 과거 실험 근거다. 실행기가 읽는 승인된 `c2_process/config/workcell.yaml`이나 불변 설정 스냅샷이 아니다. 원래 수치와 기록된 상태 문자열을 유지했으며, 이번 작업에서 원본 bag·장비·힘 신호를 재검증하지 않았다. [실기 상세](../daily/2026-09-18-candle.md)와 [보관·이관 기록](../CLAY_0918_MIGRATION.md)을 함께 읽는다.

| 확인할 항목 | 원자료와 현재 개발 기준의 구분 |
| --- | --- |
| TCP | 9/18 제어기 관측은 `GripperDA_v3`로 보고됐고 손끝값은 v1 기준으로 환산됐다. 현재 개발 기준은 그리퍼 끝점 TCP `GripperDA_v1`. 역사적 v3 관측을 v1로 이름만 바꾸지 않음 |
| 도구 끝 | 경로 waypoint는 도구 끝 m·quaternion xyzw. 그리퍼 끝점으로의 변환은 `robot_adapter.py` 책임. 당시 도구별 돌출·옆 어긋남은 그 파지에서 관측한 값 |
| 축·반지름 | 후보값 y=-2.6mm·r=34mm와 상태 JSON의 원 맞춤 y≈-0.862mm·r≈35.704mm는 다름. 본문은 손끝 폭 때문에 현 방식의 y 추정을 신뢰하지 않았다고 보고함. 두 값을 덮어 맞추지 않고 채택 근거·확인자가 필요 |
| 높이 | 후보 윗면 204.4mm와 높이 150mm의 차는 54.4mm이나 후보 바닥은 54mm로 기록됨. 반올림/추정 여부와 받침대 관계 확인 필요 |
| 각도·이음매 | 후보의 `seam_angle_deg: 0`과 주석은 당시 기록이다. 현재 미리보기 합의의 0° 정면·±180° 이음매로 승인된 설정이 아니며, base 방향·각도 원점·이음매를 별도로 대조해야 함 |
| 유효 영역 | 당시 20~65mm 높이 구간 보고는 장착 도구·그리퍼 간섭 조건에 의존함. 전체 도구의 승인된 작업 가능 영역으로 일반화하지 않음 |
| 프레임·버전 | `frame_id` 이름·설정 버전·승인자·스냅샷 ID/해시가 확정되어야 실행 계약에 연결할 수 있음. 파일의 `schema_version: 1`만으로 공통 실행 설정과 호환됨을 뜻하지 않음 |
| 날짜·실기 | 9/19 재시험은 당시 계획이며 수행 근거가 없음. 수정된 물결무늬 코드·새 3개 노드의 실기 성공으로 기록하지 않음 |

새 작업대상 등록·도구 프로파일 작성 시 위 차이를 담당자와 대조하고 승인된 설정을 별도 생성한다. 이 기록을 모니터의 모의 프로파일이나 실기 기본값에 자동 반영하지 않는다.
