## 1. 하루 요약

9/21에는 `c2_process`의 양초 접촉 측정과 준비 Action, HMI의 준비·측정 결과 저장과 경로 입력 연결, `c2_path`의 요청별 실측 형상·이미지 해칭이 main에 반영됐다. 작업 순서는 **준비 요청 → 윗면 1점·옆면 8점 측정 → 측정 원본 저장 → 스냅샷 BIND → 경로 생성 → 미리보기**까지 연결되는 방향으로 바뀌었다. 조각은 미리보기 후 별도 요청이라는 경계를 유지했다.

당일 말 `c2_path`가 받은 REAL 측정값은 **미리보기 전용**이었다. 이를 REAL 조각 승인 또는 실제 경로의 관절·충돌 검사 완료로 읽으면 안 된다.

## 3. 동작 경계와 데이터

- 준비 Action은 MEASURE와 BIND_SNAPSHOT을 구별한다. MEASURE가 성공해도 HMI가 원본을 저장하고 최종 스냅샷을 BIND하기 전에는 경로 실행 근거가 아니다.
- 측정은 윗면 1점과 옆면 8점을 사용한다. 원의 중심·반지름은 접촉으로 계산하지만 전체 높이는 운영자가 자로 측정한 설정값을 사용하고 수직축을 가정한다. `ESTIMATED`를 독립적으로 정확도가 검증된 절대 형상으로 승격하지 않는다.
- HMI는 설정·측정 원본·최종 스냅샷·경로를 ID와 원본 바이트의 SHA-256으로 연결한다. 경로와 미리보기는 같은 스냅샷을 참조한다.
- 드릴 ON 표시는 운영자의 화면 확인이다. 공정 코드의 드릴 전원 센서나 자동 ON/OFF 명령이 아니다. 그리퍼 개폐 명령도 이 공정에 추가하지 않았다.
- 준비 취소 요청과 실제 정지 확인, 측정 성공과 스냅샷 BIND 성공, 기하 미리보기와 실행 허용은 각각 다른 결과다.

## 4. 당시 검증 기록과 한계

- [HMI 준비 검증](../VALIDATION_HMI_PREPARATION_20260921.md)은 MOCK 준비·경로·실행 흐름과 실패/취소/늦은 결과를 시험해 backend 89개, 별도 ROS 경로·타입 13개, frontend 9개 통과를 기록했다. 이는 초기 HMI 준비 작업의 기록이며 최종 PR #55의 모든 연결을 증명하는 단일 시험 수치가 아니다.
- [생성 취소 검증](../validation/2026-09-21-generation-cancel.md)은 Jazzy의 `c2_interfaces`·`c2_path` 빌드, c2_path 57개, backend 선택 시험 73개 통과와 실제 ROS 취소·시간 초과를 기록했다. 로봇은 구동하지 않았다.
- [작업 영역 검증](../validation/2026-09-21-hmi-work-area.md)과 [파일 통합 검증](../validation/2026-09-21-hmi-file-integration.md)은 각각 HMI 좌표 표시와 관리 자산의 ID·해시·롤백을 확인했다. 이 수치들을 서로 합산하지 않는다.
- PR #55 관련 기록에는 ROS SIM MEASURE/BIND 왕복과 REAL 준비 요청의 결과 확인이 있다. 사용자가 현장에서 보낸 준비 요청에 대해 HMI API에 `SUCCEEDED`, 접촉 9점, `ESTIMATED`, `MEASUREMENT_ONLY`가 저장된 것을 읽기 전용으로 확인한 기록이다. 이 기록은 독립 좌표 정확도·절대 높이·실제 조각·취소 또는 비상정지 성능의 검증이 아니다. [PR #55](https://github.com/suuuhululu/C-2/pull/55)

당일 종료 시점의 REAL 경로는 미리보기 전용이다. 실제 M0609에서 측정부터 경로·최종 관절 검사·조각까지 한 번에 완료했다는 기록은 없다. 저장소의 시험 기록은 작성 시점과 환경이 다르며 이번 일지 작성 중 재실행하지 않았다.
