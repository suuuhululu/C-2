## 1. 하루 요약

9/20에는 고정 드릴 공정의 실행 보조 모듈, 이미지에서 원통 경로를 만드는 `c2_path`, HMI와 경로 Action 서버의 연결이 main에 순차 반영됐다. 그 결과 공통 타입과 HMI/MOCK에 더해 다음 범위가 저장소에 존재한다.

- `c2_process`: `engraving.py`, `joint_check.py`, `robot_adapter.py`의 IK 호출과 관련 모의·비동작 확인 코드
- `c2_path`: 이미지→SVG→2D→원통 3D 경로→기하 검증 계산 모듈, ROS 2 패키지 설정, `/c2/generate_path` Action 서버
- HMI/서버: 관리 파일 ID·SHA-256을 사용한 실제 GeneratePath 호출, 산출물 검증·등록, 전개면/원통 미리보기

다만 이 연결은 `SIMULATION/test_only`다. `process_controller_node`와 c2_process 패키지/launch, 양초 실측 모듈, 승인된 REAL 설정, 전체 경로의 실제 IK·J5/J6·충돌 검사, 공정·정지·실기 통합은 완료되지 않았다.

## 3. 경로 생성과 HMI 검증 기록

### c2_path

`validation/2026-09-20-c2-path.md`에는 계산 모듈 초안의 순수 Python 시험 43개 통과와 PR #34 경로 형식 교차 확인이 기록돼 있다. 샘플 `heart`, `heart_pair`, `heart_seam`의 형식·모의 IK를 확인했고, 이음매 경계 회귀 시험을 추가했다.

이 기록의 한계는 명확하다. 당시 환경에는 ROS 2가 없어 Jazzy 빌드·Action 서버 통합·실제 두산 `ikin`·가공을 수행하지 않았다. 이후 PR #38에서 Action 서버가 main에 들어왔지만 REAL 제한은 해제되지 않았다. 현재 반지름 34.25 mm와 CUT 허용각 ±135°는 test_only 모델이며 승인된 일반 실기값이 아니다.

### HMI ↔ c2_path

`validation/2026-09-20-hmi-path-integration.md` 기준으로 별도 macOS Jazzy 환경에서 다음을 확인했다.

- backend 47개 통과(skip 0): 기존 MOCK, 관리 산출물 로더, 실제 ROS Action/HTTP 정상·실패·중복·단절·해시 변조·실행 차단
- frontend 표시 시험 3개 통과 및 production build 성공
- 브라우저에서 PNG 업로드→경로 생성→전개면/원통 미리보기, 범위 밖 재생성 실패, 경로 노드 종료 상태 확인
- `test_only=true`, `J6_RANGE` 미검사인 결과는 공정 시작 버튼과 `POST /runs`에서 차단

이는 HMI와 경로 노드의 부분 통합 근거다. 두산 가상/실제 제어기, 공정 노드, 그리퍼, 승인된 보정 스냅샷을 연결한 시험은 아니다. 종료 시 c2_path의 `rclpy.shutdown()` 이중 호출 오류와 개발 서버 WebSocket 초기 재연결 로그가 후속 항목으로 남았다.

## 4. 공정·역할 결정

역할 연결은 다음과 같이 정리됐다.

1. 이시율: 고정 드릴 기준을 재사용하면서 `workpiece_calibration.py`로 양초 중심·높이를 측정
2. 이수현/서버: 측정 스냅샷을 ID·버전·해시로 등록해 경로 생성 요청에 연결
3. 노홍동: 실측값으로 3D 경로·미리보기 생성
4. 김세은: 미리보기 확인 뒤 같은 최종 경로의 관절·IK 조건을 검사하고 공정 진행 판단
5. 이시율: 검사된 동일 경로를 `engraving.execute_path()`로 조각

`tool_calibration.py`와 양초 측정은 별개다. 철사 고정 상태에서는 기존 장착 기준을 재사용하고 매번 전체 3점 도구 보정을 첫 통합의 선행 조건으로 두지 않는다. 생성된 경로를 `prepared_path.py`에서 다시 중심 이동하는 단계는 제외한다. 정확한 준비 요청·측정 결과·드릴 ON 확인 계약은 아직 v2 통신에 없으므로 구현됐다고 표시하지 않는다.

## 5. 안전·데이터 기준

- 드릴 철사를 사람이 제거하고 운영 절차를 바꾸기 전까지 그리퍼 열기, 자동 집기·반납·청소를 금지한다.
- 경로는 도구 끝 기준 `c2_base`, m, quaternion `(x,y,z,w)`이고 제어기 TCP `GripperDA_v1` 변환은 `robot_adapter.py`만 담당한다.
- 이미지·프로파일·측정 스냅샷·경로·미리보기·검사·실행을 ID·버전·SHA-256으로 연결한다.
- 미리보기, 최종 관절 검사, 실행은 같은 경로를 사용한다. 측정이나 설정이 바뀌면 새 경로를 생성·확인한다.
- 정지 접수와 실제 정지, Action Goal 수락과 공정 성공, 기하 검사와 실기 합격을 각각 구분한다.
