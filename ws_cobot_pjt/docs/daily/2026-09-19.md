## 4. 문제와 대응
1. **어댑터 특이점 버그 (#31)**: 세운 자세에서 quaternion→(A,B,C) 가 (180,180,0) 으로 나와 툴 Y 가 뒤집힘 → 드릴 뒷면(패드 +Y 로 74 mm)이 양초에 닿음, 첫 측정 74.3 mm 오판. 수정 후 재측정 정상.
2. **대각선 하강 충돌 (L12)**: 궤도 확인 스크립트가 홈에서 옆 여유점으로 대각선 이동 → 드릴이 양초 윗모서리를 쓸고 지나감. 보정 함수는 "윗면 +90 상승 → 바깥 → 하강" 으로 고정.
3. **거짓 접촉 (L13)**: 회전 뒤 힘 기준 −8.6 N 튐, 0.89 N·5 N 등에서 거짓 판정 2회. 터치 전 2 s 정지·기준 재설정.
4. **안전 정지 알람 7056·1055 (L14)**: 로컬 스크립트가 TCP 를 v3 로 되돌리려 수동↔자동 모드 전환한 직후부터 이동이 1.4 s 만에 정지. 브링업 재시작 + TP 에서 `GripperDA_v1` 선택 + 로컬 스크립트 v1 전환 후 정상. 정확한 알람 원문은 TP 에서 못 봄.
5. 브링업 연결 실패: USB‑LAN 빠짐 (재연결로 해결).
