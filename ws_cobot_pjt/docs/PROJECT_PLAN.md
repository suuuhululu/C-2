> 2026-09-19 적용 범위: 아래는 9/17 서비스 기획의 보관 기록이다. 현재 목표는 HMI·철사 고정 드릴이며 자동 집기·청소·반납·그리퍼 열기는 제외한다. 현재 기능·구현 상태는 [고정 드릴 결정](C2_FIXED_DRILL_20260919.md)과 [구조](SYSTEM_STRUCTURE.md)를 따른다.

## 목표와 현재 방향

고객이 제공한 도안을 정형화하고, 선 추출·곡선 근사·순서 계획·원통 좌표 변환을 거쳐 M0609가 헤라로 재료 표면에 음각을 만드는 서비스를 목표로 한다. 도안 교체 시 로봇 경로를 일일이 새로 가르치는 부담을 줄이고 가공 품질·작업 시간을 비교한다.

- 대상 서비스: 맞춤 소품·공예품 제작. 고객 수요와 지불 의사는 아직 검증하지 않은 가설이다.
- 목표 형상: 지름 70mm, 높이 200mm 원기둥. 전체 전개도는 약 219.91×200mm이며 실제 가공 영역은 여백·지그·접근 가능한 둘레 구간을 반영한다.
- 재료: 지점토 또는 비누베이스 후보. 실제 재료 상태·질량·허용 치수 오차는 현장 시험으로 정한다.
- 공구: 끝이 송곳처럼 가는 헤라. 홈 폭·깊이·속도·접촉 각도는 실측 전이다.
- 장비: M0609, 2점 그리퍼, ROS 2 Jazzy. 로봇 카메라와 이동형 베이스를 사용하지 않는다. 고객 이미지의 PC 전처리는 수행한다.
- 일정 조건: 최종 발표 9/30, 실기는 평일에만 가능. 세부 교육 일정과 내부 목표는 [프로젝트 운영 가이드](../../docs/PROJECT_GUIDE.md)의 확인 범위를 따른다.
- 첫 실기 단계는 평면 단순선 → 원기둥 접근 가능 구간의 단순선 → 대표 도안 순으로 제안한다. 평면 초안이 원기둥 실행 코드라는 뜻은 아니다.

9/17에는 지점토 평면에 선분과 정사각형·원·별을 그리는 단위 실기 수행이 보고됐다. 지점토 결을 따른 뭉침이 관찰됐으며 홈 폭·깊이·반복 성공률은 아직 기록되지 않았다. 이 결과를 F04의 원통 경로 검증이나 F05의 기존 평면 DRL 초안 실행 완료로 확장하지 않는다. 사용 코드·커밋과 개별 시험의 연결은 [0917 일지](daily/2026-09-17.md)의 보완 항목이다.

연구 결과의 대표 비교는 작업선 4,279→1,140개(73.36% 감소), 최종 좌표 16,959→14,857개(12.39%), 전개도 비가공 이동 6,118.64→1,817.54mm(70.30%)다. 모두 같은 장식 도안을 조건 정규화하여 비교한 오프라인 수치이며 실물 가공 시간·품질 개선율이 아니다.

추가 영역 비교의 Potrace 선택은 평균 마스크 IoU 89.24%, 독립 요소 140/140·빈 영역 254/263 대응이라는 보고 결과에 기반한다. 네 도안에서의 매끄러움·세부 대응 절충이며 기존 경로 감축률과 별개다. 채워진 영역 SVG를 윤곽·중심선·영역 내부 가공 중 어떤 방식으로 변환할지 F02→F03 연결을 추가 설계한다. [범위와 한계](SVG_VECTORIZATION_VALIDATION.md).

## 서비스 흐름

`도안 입력 → 정형화·SVG 생성 → 미리보기 → 경로 순서 계획 → 점토 배치 확인 → 3D 자세·세척 경로·DRL 확정 → 파지 → 가공 ↔ 세척 → 반납·복귀 → 품질 확인 → 대기`

오류가 발생하면 정상 흐름에서 분기해 후속 실행을 막고, 마지막 완료 단계와 원인을 기록한 뒤 확인 대기로 전환한다. 로봇 정지·통신 단절·가공 성공을 동일 상태로 처리하지 않는다.
