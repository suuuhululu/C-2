# 메인 프로젝트 기획 · 맞춤 원기둥 음각 서비스

2026-09-17 사용자 대화와 기존 오프라인 검증 기록을 통합했다. 사용자에게서 전달받은 조건, 설계 제안, 실행·검증 완료를 구분한다. 팀원의 담당 배정과 실기 합격 기준은 아직 확정하지 않았다. [저장소 진행 현황](../../docs/REVIEW_STATUS.md).

## 목표와 현재 방향

고객이 제공한 도안을 정형화하고, 선 추출·곡선 근사·순서 계획·원통 좌표 변환을 거쳐 M0609가 헤라로 재료 표면에 음각을 만드는 서비스를 목표로 한다. 도안 교체 시 로봇 경로를 일일이 새로 가르치는 부담을 줄이고 가공 품질·작업 시간을 비교한다.

- 대상 서비스: 맞춤 소품·공예품 제작. 고객 수요와 지불 의사는 아직 검증하지 않은 가설이다.
- 목표 형상: 지름 70mm, 높이 200mm 원기둥. 전체 전개도는 약 219.91×200mm이며 실제 가공 영역은 여백·지그·접근 가능한 둘레 구간을 반영한다.
- 재료: 지점토 또는 비누베이스 후보. 실제 재료 상태·질량·허용 치수 오차는 현장 시험으로 정한다.
- 공구: 끝이 송곳처럼 가는 헤라. 홈 폭·깊이·속도·접촉 각도는 실측 전이다.
- 장비: M0609, 2점 그리퍼, ROS 2 Jazzy. 로봇 카메라와 이동형 베이스를 사용하지 않는다. 고객 이미지의 PC 전처리는 수행한다.
- 일정 조건: 최종 발표 9/30, 실기는 평일에만 가능. 세부 교육 일정과 내부 목표는 [프로젝트 운영 가이드](../../docs/PROJECT_GUIDE.md)의 확인 범위를 따른다.
- 첫 실기 단계는 평면 단순선 → 원기둥 접근 가능 구간의 단순선 → 대표 도안 순으로 제안한다. 평면 초안이 원기둥 실행 코드라는 뜻은 아니다.

연구 결과의 대표 비교는 작업선 4,279→1,140개(73.36% 감소), 최종 좌표 16,959→14,857개(12.39%), 전개도 비가공 이동 6,118.64→1,817.54mm(70.30%)다. 모두 같은 장식 도안을 조건 정규화하여 비교한 오프라인 수치이며 실물 가공 시간·품질 개선율이 아니다.

## 서비스 흐름

`도안 입력 → 정형화·SVG 생성 → 미리보기 → 경로 순서 계획 → 점토 배치 확인 → 3D 자세·세척 경로·DRL 확정 → 파지 → 가공 ↔ 세척 → 반납·복귀 → 품질 확인 → 대기`

오류가 발생하면 정상 흐름에서 분기해 후속 실행을 막고, 마지막 완료 단계와 원인을 기록한 뒤 확인 대기로 전환한다. 로봇 정지·통신 단절·가공 성공을 동일 상태로 처리하지 않는다.

## 기능과 역할

팀은 이수현(팀장), 김세은, 노홍동, 이시율 4명이다. 담당 분야는 아직 미정이며 아래 영역에 담당자와 동료 검토자를 배정한다.

| 영역 | 담당자 | 검토자 | 완료 기준 |
| --- | --- | --- | --- |
| 공정·ROS 2 통합 | 미정 | 미정 | 모듈 연결과 실행 절차 재현 |
| 로봇 동작 | 미정 | 미정 | 문서와 실제 환경에 맞는 동작·완료 확인 |
| 그리퍼·공작물 | 미정 | 미정 | 장비 식별과 파지·해제 확인 방법 검증 |
| HMI·시험 | 미정 | 미정 | 상태·오류 표시와 시험 증거 연결 |

## 인터페이스 합의

| 기능 | 호출 측 → 제공 측 | 입력·단위·좌표계 | 출력·완료 조건 | 제한 시간·실패 처리 |
| --- | --- | --- | --- | --- |
| 도안 처리 | 웹앱 → 작업 관리자 → 경로 처리 | 원본, 재료·mm 치수, 가공 구간, 설정 버전 | SVG·경로·검증 결과·DRL 묶음 | 실패한 결과는 실행 대기열에 넣지 않음 |
| 실행 요청 | 운영 화면 → 작업 관리자 | 작업 ID, 확정 경로 버전, 현장 준비 확인 | 실행 접수와 실제 완료를 별도 확인 | 한 작업만 실행, 중복 요청 차단 |
| 로봇 실행 | 작업 관리자 → ROS 2 → 제어기 | DRL, 확인한 TCP·좌표계·가공 조건 | 제어기 상태 + 단계 완료 정보 | 오류·응답 지연 시 상태 확인, 자동 중복 실행 금지 |
| 상태 표시 | 상태 수집 → 웹앱 | 단계·선 ID·세척 횟수·시각·오류 | 마지막 확인 시각과 미확인 상태 표시 | 오래된 정상 값을 현재 상태로 표시하지 않음 |
| 품질 기록 | 작업자 → 이력 저장소 | 실측 홈 폭·깊이·결함·시험 조건 | 제품 합격·실행 결과 분리 저장 | 미측정 값을 합격으로 채우지 않음 |

위 표는 인터페이스 설계다. 제어기에서 세부 진행 단계를 전달하는 통신 방식과 그리퍼 연결부는 설치 환경 확인 후 확정한다.

## 단계별 완료 목표

- 중간점검: 핵심 기능을 보여주고 구현·모의 동작·미연결 부분을 구분한다.
- 통합 완료: 정상 공정과 대표 실패 흐름을 재현한다.
- 시연 준비: 시험한 커밋, 실행 절차, 결과, 영상, 발표 자료를 일치시킨다.

변경한 요구사항은 관련 Issue와 함께 날짜·이유·일정 영향을 기록한다.
