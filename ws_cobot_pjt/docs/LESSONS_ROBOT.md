[양초 실기 상세 기록](daily/2026-09-18-candle.md), [새 구조로의 이관 검토](CLAY_0918_MIGRATION.md)를 함께 읽는다. 당시 매회 스캔·힘 터치·자동 홈 이동 제안을 현재 고정 좌표 공정에 바로 적용하지 않는다.

## 2026-09-18

### L1. 도구가 축을 향하게 한 바퀴 돌면 J6 가 한 바퀴 감긴다
- 현상: 360° 물결무늬 중 손목이 갑자기 크게 뒤집혀 비상정지.
- 원인: 시작 J6 가 −195° 인데 A 를 270° 더 돌려 J6 한계(±360°)를 넘음. 제어기는 한계를 넘는 대신 다른 관절 해로 뒤집는다. 각도 진행 계산의 나머지 연산 버그로 J6 가 0 에서 멀어지는 방향으로 돌았다.
- 대응: 회전 동작 전에 J6 현재값과 예상 최종값을 계산해 ±350° 를 넘으면 시작하지 않는다. 시작 전 안전 높이(양초 위)에서 손목을 풀어 J6 를 0 근처로 맞춘다. 180° 회전은 movel 한 번으로 주지 않고 90° 두 번으로 나눈다(경로 모호). `c2_path` 가 옆면 경로를 줄 때도 한 획의 둘레 각도 범위와 시작각을 J6 가 단조 변화하도록 제한해야 한다.
- 코드: `clay_carving/scripts/orbit_wave.py` (`J6_LIMIT`, `unwind` 단계). 증거: bag_side_heart_0918 뒤쪽, 일지 5절.

### L2. 자세를 돌린 뒤 이동 방향 반력이 천천히 오른다 (거짓 접촉)
- 현상: 옆면 터치가 표면 4~10 mm 전에 "접촉" 으로 멈춤 (Δf 2.4~2.8 N). 출발 전 기준값이 자세에 따라 −6.8 N 까지 흔들림.
- 원인: 툴 하중·힘센서 기준이 자세마다 달라 이동 중 반력이 2~3 N 씩 완만히 올라 평탄해진다. 무른 재료용 완만 상승 판정(0.8 N 연속 2샘플)이 이 드리프트를 접촉으로 본다.
- 대응: 긴 접근(≥ 20 mm)은 급증(1.5 N ×2) 또는 정착(8 mm/3 s) 후 |Δ| ≥ 2.5 N 만 쓰고 완만 판정을 끈다. 접촉 위치는 힘이 오르기 시작한 지점으로 역산한다. 여러 점을 재면 기하(원) 잔차로 거짓 접촉을 걸러낸다(1 mm 초과면 중단).
- 코드: `orbit_wave.py`, `side_heart.py` (`first=True` 접근). 이전 기록: 9/17 bag 1559 도 같은 원인.

### L3. 뭉툭한 도구는 4 mm/s 로 접근하면 늦게 잡힌다
- 현상: 드릴 날 첫 터치가 7.8 N, 접촉 시작점보다 11 mm 뒤에서 정지. 송곳(뾰족)은 2 mm/s 에서 2~4 N 에 잡힘.
- 대응: 표면 찾기는 2 mm/s 이하, 획 시작 터치는 1.5 mm/s. 힘 임계값은 도구별 프로파일(tools.yaml)로.

### L4. 도구 끝은 패드 축에서 옆으로 벗어나 있다 (쥘 때마다 다름)
- 현상: 스캔 중심(4 mm 오차)은 맞는데 3번 노드가 중심을 못 찍음. 송곳 +4.2 mm, 드릴 −2.5 mm (툴 X 방향).
- 대응: 집은 뒤 옆면 3점 터치(축, ±15 mm)로 반지름 고정 원을 맞춰 **돌출 길이와 옆 어긋남을 같이** 잰다. 길이만 재는 `probe_touch` 한 번으로는 부족하다. 소프트웨어 오프셋은 툴 −Y 한 축이 아니라 (x, y) 두 성분.
- 코드: `side_heart.py measure`, `orbit_wave.py touch`. 일지 3절.

### L5. 같은 윗면을 다른 자세로 재면 8 mm 차이
- 현상: 45° 기울인 패드로 잰 윗면 196.1, 세운 닫힌 손끝 204.4/204.0.
- 원인: 기울이면 패드 모서리가 닿는 점이 TCP 정의점과 다르고, 닫힌 RG2 손끝의 실제 길이가 208 과 다를 수 있다.
- 대응: 좌표는 **어느 자세·어느 접촉부 기준인지** 명시한다. 가공 높이는 저장값에 의존하지 말고 힘 터치로 다시 잡는다. workcell 값은 세운 닫힌 손끝 기준으로 통일.

### L6. 손끝이 넓으면 현(chord) 방식으로 중심 y 를 못 구한다
- 현상: X 현을 축 ±15 mm 옆에서 재도 반현이 34.0/34.0/32.5.
- 원인: 손끝 Y 폭이 15 mm 넘어 어디서 밀어도 가장 넓은 곳에 닿는다.
- 대응: 세운 자세는 ±X·±Y 가 대칭이므로 Y 도 직접 밀거나, 사람 기준점을 쓴다. 자로 잰 지름을 주면 손끝 폭을 자동 보정한다(`--diameter`).

### L7. 물체가 홈 손끝보다 높을 때 홈 관절로 가면 관통한다
- 현상 (19:34): `movej HOME_J` 중 손끝이 양초 윗면 아래를 지나 충돌.
- 대응: 직선 상승 → 안전 높이(툴의 가장 낮은 점이 물체 위 +90 mm)에서 수평 이동·자세 변경 → 수직 하강. 미리 알려준 "어제와 높이가 다르다" 는 정보는 코드 상수보다 우선한다.
- 코드: `clay_scan2 --lift/--from-here/--upright`, `force_probe --no-home`, `scripts/goto_home2.py`.

### L8. TP 조작·비상정지·브링업 재시작 중엔 서비스가 응답하지 않는다
- 현상: `get_current_posx` 등이 타임아웃, `rcl node's context is invalid`. `joint_states` 는 105 Hz 로 계속 온다.
- 대응: 자세는 `joint_states` + URDF 정운동학(`scripts/fk.py`, 홈 자세로 검증 1.5 mm)으로 읽는다. 브링업 재시작 뒤엔 툴·TCP 선택이 비므로 다시 확인(`set_robot_mode 0` → 선택 → `1`).

### L9. 그리퍼 "반 열기" 는 없다
- 현상: 프리셋이 없어 완전히 열린다. 도구를 문 채 열면 떨어진다.
- 대응: 도구 교체는 사람이 잡은 뒤 연다. 스캔 끝의 자동 열기는 도구가 없을 때만.

### L10. RG2 몸체는 손끝보다 X 로 약 26 mm 넓다
- 현상: 윗면 아래 75 mm 옆면 터치에서 손끝보다 14 mm 먼저 몸체가 닿음.
- 대응: 세운 자세로 옆면을 만질 때 윗면 아래 60 mm 이상은 몸체 간섭 확인. 도구를 물면 돌출 길이만큼 여유가 생긴다(송곳 51, 드릴 63).

### L11. 패드와 TCP 의 60 mm 오프셋 방향은 자세에 따라 바뀐다
- `GripperDA_v3`(0, −60, 208) 선택 시 패드 = TCP + 60·(툴 +Y). 눕힌 홈 자세는 위, 세운 자세는 base +Y, 180° 돌리면 base −Y. 좌표를 넘길 때 v1(패드) 기준으로 환산해서 준다.
