# HMI 작업 영역 기준 · 2026-09-21

사용자가 전달한 최종 기준은 **상단 10mm·하단 10mm 조각 제외**다.
앞선 상하 20mm 제외 제안을 대체한다. 높이 150mm는 운영자가 자로 측정해 전달한 값이며,
윗면 절대 Z·로봇 실측 완료·관절 도달 가능성이 확인됐다는 뜻은 아니다.

## 좌표 기준

- `v`: 윗면을 0, 아래쪽이 양수. HMI 설명용으로 사용한다.
- `V`: 바닥을 0, 위쪽이 양수. 기존 `offset_v_mm`·`points_uv_mm`·`surface.valid_v_range_mm`의 기준이다.
- 높이 H에 대해 `V = H - v`, 구간 `[v_min, v_max]`는 `[H-v_max, H-v_min]`으로 변환한다.
- 상단 제외 a, 하단 제외 b이면 윗면 기준 `[a, H-b]`, 바닥 기준 `[b, H-a]`다.
- H=150mm, a=b=10mm이면 양쪽 모두 `[10, 140]`, 작업 높이는 130mm다.
  비대칭일 때는 숫자도 달라진다. 상단 10·하단 20mm이면 윗면 `[10,130]`, 바닥 `[20,140]`이다.
- base +Z가 위쪽이고 검증된 윗면 Z를 알고 있다면 `z = top_z - v/1000`이다.
  윗면 Z 미확정 동안 HMI는 SIM 값으로 절대 실측 좌표를 만들어 표시하지 않는다.

## HMI 구현과 현재 좌표 노드의 차이

합의 제외 길이는 [서버 설정](../backend/config/work_area.json)에서 관리한다.
서버 시작 시 변경 불가능한 `hmi_work_area_policy` 자산으로 등록해 ID·SHA-256을 보존하고,
기존 HTTP/WS snapshot에 `work_area_policy = {id, sha256, payload}`로 전달한다.
같은 설정은 같은 ID를 재사용하며 변경 시 새 자산으로 보존한다. 이 필드는 **HMI 내부 표시 기준**이며
GeneratePath가 참조하는 공통 프로파일이나 ROS 메시지를 대체하지 않는다.

화면은 스냅샷의 `surface.height_mm`와 합의 제외 길이로 작업 영역을 표시한다.
설정이 없는 구버전 서버나 파일 경로 미리보기에서는 해당 경로의 프로파일 범위만 표시한다.
잘못된 범위를 임의의 기본값으로 채우지 않는다. 전체 원통 옆면은 계속 표시하고 상하 제외 구간만
옅은 음영·경계선으로 표시한다. 작업 영역 표시로 실제 CUT·보간·접근·이탈 검증을 대신하지 않는다.

- **MOCK:** 합의 제외 길이를 모의 프로파일에 적용하고, 모의 생성·실패 진단도 해당 프로파일의 범위를 읽는다.
- **ROS:** `matching_test_profile()` 원본을 유지한다. 현재 c2_path는 85~130mm를 검사하므로
  화면에 **현재 경로 프로파일 85~130mm / 합의 기준 반영 대기**를 명시한다.
  HMI만 10~140mm로 바꾸어 요청하면 PROFILE_MISMATCH가 발생하므로 입력 스냅샷을 덮어쓰지 않는다.
- **파일로 가져온 경로:** 생성 당시 프로파일의 작업 영역을 표시한다. 과거 산출물을 새 범위로 해석하지 않는다.

따라서 이번 HMI 변경만으로 ROS의 100mm 도안 생성 실패가 해결되지는 않는다.
좌표 담당이 요청별 스냅샷 계산과 새 작업 영역을 적용해야 하며, 현재 ±135° 제한·복잡한 도안 정렬
성능 개선·파일 묶음 계약 통일은 이번 1번 작업의 범위가 아니다.

## 담당 간 유지할 경계

`surface.valid_v_range_mm`는 계속 **바닥 기준**이다. 윗면 기준 수치를 의미 변경 없이 그대로 복사하지 않는다.
실제 양초의 작업별 프로파일에 이 범위와 측정 출처를 넣는 통합은 측정·좌표 담당과 함께 진행한다.
범위 설정 통과와 로봇 관절·IK 검사는 구분하며, SIMULATION/test_only 실행 차단은 유지한다.
공통 GeneratePath v2·경로 파일·입력 ZIP의 필드와 기존 자산 ID·해시는 변경하지 않았다.

## 적용

화면을 다시 빌드하고 백엔드를 재시작한다. 실행기 사용 중이면 Ctrl+C 후 같은 명령으로 다시 시작한다.
브라우저를 새로고침하면 전개면 아래와 설정 정보에 합의 범위·바닥/윗면 기준·현재 프로파일 차이가 표시된다.

```bash
cd ws_cobot_pjt/frontend
pnpm build
```

브라우저 새로고침만으로 실행 중인 백엔드 설정이 갱신되지는 않는다.
이번 작업은 로봇 동작·그리퍼 명령을 추가하거나 실행하지 않는다.
