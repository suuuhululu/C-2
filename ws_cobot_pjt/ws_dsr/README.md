# ws_dsr · 로봇·그리퍼 실행환경

메인 프로젝트가 사용하는 로봇·그리퍼 드라이버와 실행환경 패키지를 `src/`에 준비한다. 팀 공정 패키지는 이곳에 넣지 않고 옆의 `ws_cobot1/src/`에서 관리한다.

강사 예시는 RG2 연동 환경이지만, 전달받은 폴더명만으로 실제 장비 모델이나 준비된 드라이버 버전이 확인된 것은 아니다. 현재 소스·설정·실행 프로그램은 설치하지 않았다.

- 외부 패키지는 [의존성 기록](../../docs/DEPENDENCIES.md)에 출처·브랜치·커밋·필요한 설치 과정을 기록하고 같은 버전으로 준비한다.
- `DoosanBootcamInt1`, `doosan-robot2`, `onrobot_rg2`처럼 지정한 외부 원본 폴더는 Git에서 제외한다. 같은 두산 패키지를 여러 원본으로 동시에 넣지 않는다.
- 팀이 직접 작성하는 실행환경 패키지는 다른 고유 이름으로 `src/`에 두어 Git에서 공유한다.
- 수업용 `ros2_ws`의 build/install/log를 복사하지 않는다. 빌드·환경 적용은 [워크스페이스 가이드](../../docs/WORKSPACES.md)를 따른다.
