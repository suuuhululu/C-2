# Docker 구성

팀에서 사용할 Dockerfile·Compose 설정과 이미지 버전·빌드·실행 절차를 이 폴더에 둔다. 2026-09-17 C-2에는 팀 컨테이너 정의 파일이 아직 없다.

외부 실행환경에서는 MSI의 Docker 에뮬레이터 가상 동작과 이시율 PC의 dsr_emulator 3.0.1 설치·실행이 보고됐다. 이는 이 폴더에 팀 컨테이너 구성이 완성됐다는 의미가 아니다. 출처와 PC별 확인 범위는 [의존성 기록](../../docs/DEPENDENCIES.md)을 따른다.

이시율이 공유를 제안한 `setup_host.sh`는 아직 저장소에 없다. 파일을 제공받으면 설치 대상·버전·시스템 변경 내용을 별도 PR에서 검토한다. 현재 동작하는 Ubuntu 설치를 문서 정리 때문에 다시 설치하지 않는다.

- 실제 OS·CPU·Jazzy·시뮬레이터 조건을 확인한 뒤 이미지를 선택한다.
- 비밀 값은 이미지·설정 파일에 넣지 않고 로컬 환경 설정으로 분리한다.
- 이미지 파일이나 실행 중 생성된 데이터 대신 재현할 수 있는 정의 파일을 공유한다.
- 강사 실행환경의 출처·버전은 [의존성 기록](../../docs/DEPENDENCIES.md)에 남긴다.
