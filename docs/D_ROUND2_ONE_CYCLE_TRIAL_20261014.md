# 이전 한 사이클 시험 안내의 보존 위치

기존노랑2×2 slot1/(11,11,L1) 한사이클은새8블록사전배치와호환되지않는다. 당시안내와실기완주1회자료는역사적증거로보존했다. 해당좌표에는이제P02/P06파랑블록이있다.
