# 장치·좌표·실측 확인

## 최종 MVP 직접 결착에 필요한 실측 (2026-10-07)

[최종 MVP](10_FINAL_MVP.md)는 Robot이 supply board에서 assembly board에 직접 결착하는 흐름입니다. **아래 전달판·pose 배열은 기존 측정 원자료**이며 직접 결착 좌표·궤적 검증으로 재사용하지 않습니다. 문서 수정으로 장치를 움직이거나 값을 변경하지 않습니다.

| 새 확인 대상 | 필요한 증거 |
|---|---|
| 조립판 좌표 변환 | assembly grid/board·camera·robot base·tool frame의 관계, 단위·원점·보정 버전 |
| 접근/접촉 인계 | 유효 접근 경로·pre-contact 도달·단일 제어권·정지/취소·파지 확인 |
| 접촉/삽입 | F/T 취득·영점/하중·시간 정렬, 삽입축·힘/변위·XY 탐색의 실측 한계와 실제 결착 정답 |
| 사람 지지 | LOW/HIGH 규칙·블록/영역/방향, 지지 자세·응답하는 손·알림·동작 중 사람 협업 조건 |
| 최종 Vision | 필요한 영역·관측 자세·손 가림·유효성·완성상태의 독립 정답과 Backend 연결 |

지지 유지 가정과 제스처는 로봇 안전 기능을 대신하지 않습니다. 기존 ‘사람 이탈/손 없음’ 전달 조건을 지지 동작 중 조건으로 그대로 적용하거나 자동 삭제하지 않고, 지지와 촬영의 실제 협업 조건을 담당자와 다시 검증합니다. 지속 hand-presence·자동 지지 이탈 감지는 MVP 제외입니다. 임계값·TCP·속도·힘은 이 문서에서 추정하지 않습니다.

## 기존 Day4 전달·측정 기록

갱신: 2026-10-04. Robot은 고정 공급 위치에서 place board로 전달하고 사람은 별도 조립판에 배치합니다. 조립판 grid → Robot 변환은 Day 4에서 제외합니다(E01·E05). 아래 원본 pose는 보존한 측정 기록이며 실행 설정이 아닙니다.

| Robot | M0609 | 컨트롤러 펌웨어·TCP / tool·제어 경로 |
| Camera | 사용자 재확인: RealSense D435i | 장착 / 고정·RGB / Depth / camera info·보정 |
| Gripper | OnRobot RG2 | 폭 / 힘 / 파지 피드백·제어 경로 |

RG2는 [OnRobot의 2-finger gripper](https://onrobot.com/en/products/rg2-finger-gripper)입니다. ROS·장치 환경에서 아래 읽기 전용 확인을 수행하고 필요한 결과만 기록합니다.

```bash
python3 --version
source /opt/ros/jazzy/setup.bash
ros2 pkg list | rg -i 'dsr|doosan|onrobot|realsense'
```

실제 패키지명과 소스 경로를 확인한 뒤 package.xml 버전·Git commit·펌웨어를 구분해 기록합니다. 전체 환경변수·secret은 공유하지 않습니다. source 명령은 해당 설치가 있는 PC에서만 사용합니다.

## 조립판·GT·Camera

공통 소프트웨어의 지원 plate는 24×24점, 최대 5층, 노랑 / 파랑의 4점 / 6점입니다. 최신 B04의 원점·축·기준점·layer·방향은 아직 상세 확인이 필요합니다.

[의자1 원자료](reference/assembly_board_블럭의자1/ground_truth_notes.md)에는 붉은 원점·최소 X/Y anchor·0-based layer·2×2 / 2×3 orientation 기록 규약과 일부 확인 좌표가 있습니다. 이를 공통 계약에 채택할지는 홍동·세은·시율·수현이 확인합니다. 미확정 GT는 사진만으로 추정하지 않습니다. [의자2](reference/assembly_board_블럭의자2/chair_2_ground_truth_notes.md)의 빨간 블록은 최신 노랑 / 파랑 지원 밖이며 Day 4 유효 입력으로 자동 사용하지 않습니다.

홍동은 Baseplate 기준점으로 이미지 / grid 대응을 보정하고 알려진 배치로 검증합니다(E06). 최대 5층·하부 가림·종류 / 색 / 방향을 실제로 판별할 수 있는지 확인합니다. D435i 고정 / Robot 장착 구성과 보정 유효 조건도 기록합니다. 이전 Viewer 스크린샷을 원본 Depth 데이터로 취급하지 않습니다.

기록 초안: 촬영 조건, Camera 모델, 보정 버전, 확인 grid, 실제 인식값, 신뢰 / 오류, 가림, 검사 범위, 담당, 시각. 허용 오차·안정 프레임·신뢰도 임계값은 시험 후 합의합니다.

## 공급 슬롯·전달 위치·정지 시험

종류·색상별 공급 슬롯 1~6을 순차 사용합니다. 다음 Step·재계획에도 순서 유지, 6번 뒤 보충 확인 후 1번으로 초기화합니다(D02·D03). 이전 C01 / C02는 과거 두 위치 시험 기록이며 최신 전체 슬롯 배열을 대신하지 않습니다.

| 확인 | 책임 / 기록 |
|---|---|
| 슬롯 배열 | 종류·색상·slot ID·실측 pick 좌표·frame / 단위 / TCP / tool·장치와의 연결 |
| 공급 가정 | 재고 충분 가정, 실제 보충 담당·완료 신호·실패 시 다음 번호 갱신은 확인 필요 |
| 전달 장소 | place board 좌표·경계·높이·완료 판정, 조립판 target과 구분 |
| motion | 실제 Home / Ready·접근 / 후퇴·속도 / 가속도·gripper 설정 시험 |
| 정지·부분 완료 | 실제 STOP / 취소·쥔 블록 처리·전달 여부 확인·중복 방지·재개 |

수현이 고정 좌표·구간·parameter를 시험합니다. 미측정 슬롯을 이전 pose로 복제하거나 임의 좌표·속도를 생성하지 않습니다. 물리 간격·파지 힘·반복 횟수·통과 기준은 실물 시험으로 확정합니다. Mock 성공은 실기 성공이 아닙니다.

관련 L1~L3와 실제 작업 환경·정지·TCP / tool·그리퍼 확인 후 담당자가 REAL 시험을 수행합니다. 이번 문서 PR은 장치를 움직이지 않습니다.
