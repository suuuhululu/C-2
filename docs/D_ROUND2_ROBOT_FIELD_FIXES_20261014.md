# Round2 로봇 현장 수정과 검증

기존 한 사이클 실행과 새 사전 배치가 섞여 잘못된 목표로 이동하던 문제, 접촉 뒤 잔류 반력으로 상승이 다시 중단되던 문제, `None` 힘값 비교 오류를 수정했다. 노랑 2×2 슬롯4 → 파랑 2×3 슬롯3 → 노랑 2×3 슬롯5를 수행하는 세 사이클 코드와 공급·조립 팝업을 제공한다. 사전 배치와 실행 순서는 [세 사이클 안내](D_ROUND2_THREE_STEP_TRIAL_20261014.md)를 따른다.

## 제어 조건

현장 시험 설정은 삽입·빈 패드 가압의 접촉 반력 45N과 일반 이동의 `motion_force_stop_n=null`을 분리한다. `target_only_motion=true`에서는 TCP 좌표·자세 오차와 IK/FK 수치 차이를 이동 완료의 차단 조건으로 사용하지 않는다. 컨트롤러의 이동 종료를 확인하고 오차는 진단 로그에 남긴다. 영상 신선도, 장치 피드백, 기존 ESC·STOP 흐름을 유지한다.

과거 실제 한 사이클 완주는 해당 교시 조건에서의 명령 종료 기록이다. 이후 T2 중단에서 목표보다 약 2.77mm 높은 위치의 반력 중단을 확인했다. 임계 반력 도달만으로 완전 결착을 판정하지 않는다. 과거 실패·완주 로그는 지우지 않았다.

## T2 교시와 영상 XY

이번에 기록한 T2 중앙 파지·완전 결착·빈 패드 윗면 접촉 pose를 적용하며 이전 +10mm 후보는 추가하지 않는다. 파지 높이 약 8mm는 사용자 추정으로 기록한다. 실측 패드 XYZ·자세 전체를 사용하며, 파지 오프셋을 보상해 TCP를 옮겨도 블록의 원래 목표와 패드의 목표는 유지한다.

조립 팝업의 1~4로 대응 목표 변을 선택하고 E로 같은 몸체 윗면 모서리를 고른다. X는 화면의 dX/dY를 TCP에 적용하며 I 착좌 XY도 변경한다. 변 선택·X 이후에는 각도 이력을 새 영상으로 다시 쌓는다. 예상 윗면 평면 또는 등록된 깊이로 역투영하며 높이 근거를 화면에 표시한다. 현재 투영의 실물 좌표 정확도, 깊이 배경 혼입과 방출 후 블록 재관측은 미검증이다.

## A 전략을 받는 로봇 실행 분기

A PR50의 원본 `ROBOT_GRIP + RELEASE_PRESS`와 도움 대상 정보를 D 작업 데이터에 보존한다. 명시된 상공 해제 pose로 놓은 뒤 먼저 수직 후퇴하고, 고도에서 실측 패드 XY·자세로 이동해 가압한다. 사람 PRESS가 지정되면 로봇 가압을 추가하지 않는다. 입력된 접촉 힘값과 공중 해제 높이를 보존한다.

빈 패드가 닫힌 상태는 다음 준비 조회까지 전달하고, 다음 파지 전에 개방한다. 새 그리퍼 명령을 시작하면 이전 빈 패드 상태를 지운다. STOP 뒤에 이미 수행한 개방·가압을 반복하지 않는다. 이 PR의 로봇 실행 분기는 별도 A–D 서비스 연결 PR에서 호출한다. 실물 상공 해제 높이는 미정이며 완전 결착 pose로 자동 대체하지 않는다.

## 오프라인 검증

최종 게시 사본에서 외부 연결을 차단한 native 전체 **1,509개**, 영상 XY·가상 격자 **49개** 검사가 통과했다. 합성 세 사이클 replay에서 T1→T2→T3 진행, 사람 지지 요청과 빈 패드 전이를 확인했다. Replay는 이상적인 이동 종점과 반력을 부여하며 물리 접촉·충돌·영상 yaw를 재현하지 않는다. 결과 XML·source SHA는 현장 폴더의 `reports/round2_xy_strategy_link_20261014/`에 보관한다.

실물 최신 교시·XY 보정과 놓기·가압 전략은 아직 검증하지 않았다. 로봇 명령 종료 후 B 검사 책임과 `assembly_completion=false`, `current_update=false`를 유지한다. 소스 게시와 실물 결착 성공·전체 서비스 완료를 구분한다.
