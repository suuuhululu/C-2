현재 사용자 조건: 다른 실기 시험 중. 이번 작업에서는 로봇/카메라/서비스에 연결하지 않으며 배치를 변경하지 않는다. 아래 현장 측정 절차는 시험 종료 후를 위한 안내이며 지금 실행하지 않는다.

노랑2×2 챌린지: 추가 측정 안내 (2026-10-15)

현재 단계: 측정 준비. 실제 측정 및 장치 이동은 수행하지 않음.

1. 현재 블록 위치, 파지/개방 여부, 다른 시험 사용 여부를 확인한다.
2. 로봇과 판을 움직이지 않고 전체 배치 사진을 먼저 확보한다.
   조립판, 노랑 블록, 양쪽 패드가 어느 위치인지 보여야 한다.
3. 현재 파지 중이면 블록을 재파지하지 않는다. 같은 정지 상태에서
   기존 읽기 전용 관측기로 TCP/tool/폭/RGB를 기록한다.
   블록을 놓은 상태이면 기존 파지 관계가 유지된다고 기록하지 않는다.
4. 측정 구도: 윗면/몸체 모서리가 잘리지 않은 영상과 서로 직교하는 두 측면.
   측면은 패드 아래 끝, 블록 아래 끝, 윗면, 파지면을 함께 보이게 한다.
   자는 측정할 모서리와 같은 평면에 둔다. 사진은 선별 자료이며
   일반 사진 두 장만으로 BASE 6D pose를 확정하지 않는다.
5. metric pose 후보는 올바른 조립판 RGB-D + 같은 정지 TCP + 검증된
   카메라/BASE 변환으로 산출한다. 카메라/변환/가림/깊이 품질이
   부적합하면 위치 등록이 가능한 고정 지그/측정 도구가 필요하다.
6. 최초 걸림의 측면 관찰은 별도 자료로 기록한다. 이미 보유한 사람 시연을
   우선 사용하고, 추가 시연은 로봇 작업공간 밖의 별도 블록으로 한다.
   먼저 닿는 밑면 부위, 접촉하는 stud, 회전 방향을 식별한다.
   접촉부가 가려지거나 이동하면 실제 고정축은 UNKNOWN으로 둔다.
7. 새 파지/재파지가 있었다면 새 grasp_id와 동시 TCP–블록 자료를 만든다.
   과거 착좌 TCP를 새 파지에 연결하지 않는다.

기존 공급/착좌 교시 반복 및 상공 원호/접촉/분리 시험은 이번 단계에 포함하지 않는다.
측정값이 없으면 null 유지. 실행 설정은 변경하지 않는다.
