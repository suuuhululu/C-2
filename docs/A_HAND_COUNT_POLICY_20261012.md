## 변경과 현재 결과

- assembly_geometry: 필요한 하부 지지를 모두 보존하면서 손 수 때문에 조합을 제외하는 분기 제거.
- assembly_optimizer: 후보 재검사의 최대 2손 조건 제거. 필요한 손 수와 도움 비용은 유지. 실패 시 실제 막힌 블록·조건을 기존 block/reason 필드로 공개 반환하고 원시 최적화 결과에 재현 가능한 막힘 상태를 보존.
- assembly_contract: 현재 Action.human_hands_used의 maximum=2 제거. API 버전은 0.5.1을 유지하며 보존용 v4 schema는 변경하지 않음. 음수 금지 및 손 수/동작 수 일치 검사는 유지.

원래 승인 설계를 변경하지 않고 전체 24단계 계획이 생성됐다. CPU 약 0.82초, GPU 약 0.47초의 단일 사례 측정이다. 모든 24블록 설계의 시간 보장은 아니다. 손 수별 단계는 0손 9개, 1손 9개, 2손 3개, 3손 3개다. 전체 계획→3손 단계 재평가→이동 후보까지 현재 계약으로 통과했다. 필요한 실제 참여 인원·준비 응답은 D에서 관리한다.
