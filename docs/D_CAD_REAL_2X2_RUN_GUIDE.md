공급판은 항상 채워져 있다는 전제로, 노랑 2×2 1~3번과 파랑 2×2 1~2번을 사용한다. 빈 조립판과 빈 그리퍼를 준비한다. 빈 그리퍼는 닫혀 있어도 첫 동작에서 55mm 개방하며, 실제 개방 44mm 초과를 확인한 뒤 팔을 움직인다. 시작 영역 기본값은 assembly다. 설계는 노랑→파랑→노랑→파랑→노랑, 1~5층, `(11,11)`이다.


화면에서 시험 준비를 확인하고 C에게 `좋아요`라고 답한다. C의 기존 LLM 설명 함수에 **색상·좌표·층·방향을 포함한 설계 전체**를 먼저 전달하고, C 승인 후 A→D를 진행한다. LLM 호출이 실패하면 실행을 시작하지 않는다. LLM이 실제 조립 결과를 관측하는 시험은 아니다. 음성 승인을 사용하려면 STT/TTS 환경도 준비한 뒤 `bash scripts/cad_trial_ms02.sh stack --voice`로 실행한다.

각 Step의 pre-contact 정렬 확인과 정지 방법은 아래 4절과 같다. `prepare`는 같은 5층 설계의 화면/계산만 확인하며 LLM·장치를 호출하지 않는다. `real`은 고정 설계의 오프라인 C 승인을 사용한다. `stack`은 설계 전체를 실제 LLM에 전달한다. 이전 1개/2층 시험 파일도 그대로 사용할 수 있다.

**공급 순환:** 모든 색상·블록 종류별로 `1→2→3→4→5→6→1`을 독립 반복한다. 빨강 1×2도 자동 선택은 1~6번이다. 6번 사용 때문에 보충 대기나 확인 버튼을 띄우지 않는다. 공급판 슬롯은 항상 채워져 있다는 사용자 운영 전제다. 설계는 최대 40개 제한을 유지하며, 슬롯·재고 조건을 C 음성 설계에 추가하지 않는다. 집기 실패·STOP을 자동 재시도하지 않는다. 지원 규격/방향은 문서 상단의 최신 범위를 따른다.

## 4. 파랑 한 개 집기→체결

빈 조립판, 파랑 2×2 **1번 슬롯**, 빈 그리퍼를 준비한다. 시작 위치는 기본 `assembly` 영역이며, 이후 빈 상태로 전달판 상공→몸통 우회→공급판 순서로 이동한다. 시작 위치가 다른 영역이면 아래 명령을 그대로 사용하지 말고 본문 마지막의 시작 위치 옵션을 사용한다.

두 번째 터미널에서 실행한다.

```bash
cd /home/ms-02/C_2
bash scripts/cad_trial_ms02.sh real interfaces/fixtures/cad_trial_blue_single.json
```

1. 화면 상단의 **REAL** 표시와 파랑 2×2 `(11,11), 1층` 후보를 확인한다. 좌표는 Planner 공통 좌표이며 조립판 시험 grid와의 축 변환을 계산에 적용한다.
2. 기존에 검토한 좌표·경유점·실행 설정과 장치/시작 위치/공급판/빈 판 준비를 확인하고 **시험 준비 확인**을 체크한다. 이 체크는 작업자의 시험 검토이며 물리 성공 기록이 아니다.
3. C에게 `좋아요`라고 답변한다. C APPROVE 후 A 계산과 D의 실제 무이동 상태 조회를 거쳐 자동으로 집기·이송한다. 가짜 RobotState를 REAL 실행에 사용하지 않는다.
4. pre-contact 도달·정지·파지 유지 확인 후 멈춘다. 실제 블록의 XY 정렬과 평행 상태를 직접 보고 **pre-contact 정렬 확인 후 체결 진행**을 누른다. **기존 D 체결 코드가 새 정렬 근거를 요구하므로**, 이 첫 실물 시험에는 이 확인이 필요하다. 30초 안에 확인하지 않으면 체결하지 않고 보류/정지한다.
5. D가 기존 native 35N 체결, 개방 48mm, 수직 후퇴를 수행한다. `TRIAL_EXECUTION_FINISHED`는 로봇 실행 구간이 끝났다는 뜻이다. 실제 체결 상태는 작업자가 확인한다.

**정지**는 즉시 D에 요청한다. `STOP_ACCEPTED`는 수신 확인이며 실제 정지 증명이 아니다. 기록의 `STOP_VERIFIED` 또는 `STOP_UNVERIFIED`를 확인한다. 오류·STOP 이후 자동 재시도/복구/남은 슬롯 재사용은 하지 않는다. 창을 닫을 때 실행 중이면 먼저 정지를 요청하고 D 종료 응답을 기다린다.

블렌딩 도중 중단된 배치는 진행 정도를 확인하지 않고 다시 실행하지 않는다. 이 경우 일반 재개는 비활성화되며 경로/파지의 현장 복구 확인이 필요하다. `CONTACT_TARGET_DRIFT`는 체결 후 목표 XY 오차가 2mm를 넘어서 개방을 보류한 상태다. 35N 도달은 완전 체결 증명이 아니므로 실제 맞물림 상태를 확인한다.


**C 음성 설계 요청**을 누르고 원하는 구조를 말한다. 생성 후보를 화면에서 본 다음 준비 항목을 체크하고 **C 음성 승인 대화**로 승인한다. 노랑/파랑 2×3·빨강 1×2와 지원 방향도 포함하며, A가 로봇 단독 경로를 만들 수 없는 방식은 사유를 표시하고 보류한다. 지원되지 않는 작업을 다른 동작으로 임의 대체하지 않는다. 음성/API·실제 카메라/장치 실행은 오프라인 검증에 포함하지 않았다.
