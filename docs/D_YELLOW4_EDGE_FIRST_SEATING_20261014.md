# 노랑4점 한 블록: 한쪽 접촉 후 회전 결착 시험 준비

사용자가 제공한 `20261014_105637.mp4`(약6.63초)와 `20261014_105608.jpg`를 확인했다. 영상 약2.4초에서 기울인 노랑 블록의 한쪽 밑부분을 먼저 접촉시키고, 약3.6~5.4초에서 눕혀 수평 안착시키는 동작이 보인다. 손에 가려진 실제 stud 걸림 순간·접촉점·힘·정확한 각도·완전 체결 여부는 영상으로 확정하지 않는다.

사진에는 외곽 벽, 내부 중앙 튜브, 보강 리브가 보인다. 순차적인 stud 진입을 시험할 근거는 있지만, 사진만으로 치수나 허용 변형·회전각을 측정하지 않는다. 영상은 사람이 아래 파랑 블록을 지지하는 상태이며 로봇/조립판 고정과 구분한다.

이후 사용자는 **먼저 닿는 부분이 실제 stud에 걸리는 부분이며 조금 더 밀어도 더 들어가지 않는다**고 확인했다. 따라서 이 시연의 기계적 걸림은 작업자 관찰 근거로 채택한다. 실제 로봇이 센서로 걸림을 자동 판정한 기록과는 구분한다. 시험 상태는 단순한 첫 접촉보다 `STUD_ENGAGED_TRANSLATION_BLOCKED`를 기준으로, 직선 진입 대신 걸린 쪽을 지점으로 눕히기로 전환하는 구조다.

## 동작의 핵심

1. 기존 중심 파지/목표 좌표/yaw 정렬로 목표 상공에 도착한다.
2. 노랑2×2만 의도적으로 roll 또는 pitch 방향으로 기울인다.
3. 먼저 들어갈 쪽을 접촉시키고 stud 진입을 확인한다. 접촉 반력 증가만으로 stud 걸림이라고 확정하지 않는다.
4. 접촉점을 중심으로 XYZ 이동과 자세 회전을 함께 수행해 눕힌다. TCP 위치를 고정하고 회전하면 바닥 접촉점이 움직일 수 있다.
5. 안착을 확인한 뒤 놓는다. 필요하면 기존 닫힌 패드 수직 누르기 시험을 별도로 이어간다.

의도적으로 기울이는 동안 기존 자동 roll/pitch 수평 복귀 루프를 동시에 실행하면 두 제어가 서로 상쇄된다. 이 구간은 별도 상태로 구분해야 한다. 먼저 닿은 stud가 두 개이면 접촉선을 축으로 보는 모델을 시험할 수 있고, 한 점 접촉이나 접촉 위치 이동이면 고정 접촉선 모델과 다르다.

원호상의 계산 waypoint에서는 접촉선을 유지한다. 실제 MoveL로 점 사이를 이동하면 직선 보간이므로 접촉선 유지의 근사이며, 실물 제어에 연결할 때 구간 사이의 접촉 변화도 확인해야 한다. 위치 궤적만으로 일정 가압을 유지했다고 표시하지 않는다.

## 준비한 코드와 범위

`app/edge_first_seating.py`는 주어진 기준 TCP·접촉선·기울기에서 접촉선을 유지하는 TCP 원호와 회전 자세를 계산한다. 축을 Base X/Y에 고정하지 않고 두 접촉점으로 받는다. 파지/안착 위치를 원본 설정에서 덮어쓰지 않고, 다른 블록/일반 step에 적용하지 않는다.

```bash
python3 robot_control_integration/scripts/yellow4_edge_first_preview.py \
  --output /tmp/yellow4-edge-first-preview.json
```

기본 fixture는 **합성 로컬 좌표**로 동작 원리를 검증하는 예제다. 10°는 예제 입력이며 영상 측정값·권장 실물 각도가 아니다. 이 명령은 장치에 연결하거나 로봇을 움직이지 않는다. `--execute` 경로는 추가하지 않았다.

기존45N은 위치 누르기의 중단값이다. 새 방식에서 최초 접촉/걸림을 식별하는 값으로 그대로 사용하지 않는다. 실물 연결 때에는 접촉으로 인한 회전 저항·모멘트, 아래 블록의 지지, 실제 파지 미끄러짐과 유효 회전축을 함께 확인해야 한다. 이번 코드에는 이 검증이 끝난 것처럼 표시하는 접촉/체결 성공 판정이 없다.

현재 준비 완료는 **한 블록용 기하 preview와 수학적 불변량 시험**이다. 최초 접촉 관측·접촉 후 로봇 회전·자동 stud 걸림 판정의 실물 실행 코드는 아직 연결하지 않았다. 영상/사진 원본은 로컬 파일로 보존하고 PR에 업로드하지 않는다.
