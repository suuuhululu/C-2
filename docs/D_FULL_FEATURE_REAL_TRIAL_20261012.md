## PR #35 시점 동작 (최신 변경은 맨 위 절 참조)

- 공급판: 하강 → 35mm/40N 파지. 슬롯은 실제 PICKUP_CLOSE 성공 시 한 번 소비하며 각 종류·색상에서 1→2→3→4→5→6→1 순환한다.
- 조립판: 목표 TCP +20.1mm까지 접근 → 6mm/s 저속 결착 → XYZ 전체 힘 크기 35N 이상에서 정지 → 실제 정지 확인 → 그리퍼 개방. 목표 힘 35N을 명령하는 동작이 아니다. 허용 목표점 초과는 10mm다.
- 상승·경유·하강 직전까지 연속 운반한다. 돌아올 때 현재 Step 공급 슬롯 상부로 복귀하고 다음 Step에서 새 슬롯으로 이동한다.
- 정지 허용범위는 5mm/s·5°/s, 위치 1mm·자세 1°다. 실제 motion_status·새 피드백·장치 오류 확인을 유지한다.
- 노랑/파랑 6점 90° 조립 목표에 Base X +1.5mm를 한 번 적용한다. 노랑/파랑2×2 파지 축 회전90°에는 Base X −1.5mm를 추가한다. 2×2 0°와 공급판 교시값에는 적용하지 않는다.
