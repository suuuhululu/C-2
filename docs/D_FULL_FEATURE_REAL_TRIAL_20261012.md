## 실행

```bash

```

기존 옵션 이름은 유지했으며 접촉 정렬 시험 대신 현재 반력 정지 프로필을 선택한다. 시험 소스는 같은 checkout의 `robot_control_integration`을 사용한다. 설치된 DRCF2 드라이버는 ms-02 기존 설치 경로를 사용하고 READY.json의 라이브러리 해시를 검사한다. 다른 설치 경로는 `C2_DRIVER_ROOT`, 별도 D 소스는 `C2_ROBOT_ROOT`로 지정한다. 드라이버 바이너리·API 키는 저장소에 포함하지 않는다.

## 현재 동작

- 공급판: 하강 → 35mm/40N 파지. 슬롯은 실제 PICKUP_CLOSE 성공 시 한 번 소비하며 각 종류·색상에서 1→2→3→4→5→6→1 순환한다.
- 조립판: 목표 TCP +20.1mm까지 접근 → 6mm/s 저속 결착 → XYZ 전체 힘 크기 35N 이상에서 정지 → 실제 정지 확인 → 그리퍼 개방. 목표 힘 35N을 명령하는 동작이 아니다. 허용 목표점 초과는 10mm다.
- 상승·경유·하강 직전까지 연속 운반한다. 돌아올 때 현재 Step 공급 슬롯 상부로 복귀하고 다음 Step에서 새 슬롯으로 이동한다.
- 정지 허용범위는 5mm/s·5°/s, 위치 1mm·자세 1°다. 실제 motion_status·새 피드백·장치 오류 확인을 유지한다.
- 노랑/파랑 6점 90° 조립 목표에 Base X +1.5mm를 한 번 적용한다. 노랑/파랑2×2 파지 축 회전90°에는 Base X −1.5mm를 추가한다. 2×2 0°와 공급판 교시값에는 적용하지 않는다.
- 손바닥은 인계 요청이며 일반 STOP으로 대체하지 않는다. 트레이 하강 명령 전 손이 들어오면 하강/개방 없이 새 RECEIVE를 요청한다. 실제 정지가 확인되고 하강 명령 전 보류임이 확인된 상태는 재개를 허용하며 새 수신 신호를 확인한다.
- 실제 거부된 슬롯2 경로의 선두 0.026535mm 이동으로 반경 0.013002mm가 생성됐다. 펌웨어 최소 반경 1mm보다 작아 오류1205가 발생한 것이다. 이미 도착한 선두점만 제거하고, 남은 중간 반경이 1mm 이하이면 명령 전 보류한다. 최종점은 유지한다.
- 승인 후 계획 실패는 구조화된 NO_FEASIBLE_ORDER로 C에 전달한다. 유지 응답과 불명확한 응답은 보류하며 자동으로 같은 수정 질문/계획을 반복하지 않는다.

## 교시 자료

`robot_control_integration/fixtures/teaching_sources/operator_*.json`은 현장 승인 원자료의 동일 복사본이다. 로컬 로그에 원자료가 있으면 그 경로를 사용하고, 없으면 이 복사본을 읽는다. 명시한 교시 경로가 없으면 오류로 처리한다. 측정값을 새로 생성하지 않는다. 5층·빨강 2점은 소프트웨어 범위이며 REAL 검증 완료 범위가 아니다.

## 후속 실물 관찰 · 2026-10-13 09:25 KST

Job 52b1c8cc-c855-4f9c-8724-bbbefd5494a4의 S02는 파랑2×2 슬롯2를 정상 선택했다. 설계 방향0°와 별개로 A의 파지 축 y에 따라 집은 후 운반 중90° 회전했다. 기존2mm 보정은 Base XY (-0.005643, -1.999992)mm이며 보고된 Base X 약+2mm 오차와 방향이 다르다. 사용자의 추가 지시로 회전 때 Base X −1.5mm를 적용했다. 새 보정의 실물 정확도는 아직 미검증이다.

S04는 A가 HUMAN_ASSEMBLY를 선택했다.
