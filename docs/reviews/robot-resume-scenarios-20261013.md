full-real 공급 접근은 이번 후속부터 MoveB를 끄고 단독 MoveL로 진행한다. 이송 블렌딩의 재개 조건은 블록을 쥔 loaded 구간에 계속 적용한다.

## 입력의 의미와 범위

- `OPERATOR_CONFIRM`은 현재 활성 요청 ID에 연결된 HMI 답변이다. 버튼을 누른 시각은 D에서 기록한다. 이전 요청/정지된 실행의 클릭은 수락하지 않는다. 화면의 중복 클릭은 같은 명령을 두 번 보내지 않는다.
- 인계 버튼 답변은 같은 실행의 개방 한 번에만 사용한다. 개방 완료 또는 재개/새 Step에서 해제한다. 버튼 응답 후 카메라 손 모양이 UNKNOWN으로 바뀌어도 인계를 다시 막지 않는다.
- 실제 Robot 정지/파지/장치 상태는 별도로 검증한다. 영상 인식 실패와 Camera 장치/피드백 자체의 실패를 구분한다. Camera 초기 연결 실패·프레임 수신 장애의 기존 장치 오류 처리는 이번 수정 범위에 포함하지 않았다.
- 프로필에 `operator_cue_buttons=True`를 명시한 full-real 시험에 적용한다. 기존 독립 시험의 입력 의미는 유지한다. B는 여전히 가짜 관측이며 실물 조립 완료 증거가 아니다.
