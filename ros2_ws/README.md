# ros2_ws · 수업·미니 실습

목표는 수업에서 배운 기능을 작은 단위로 이해하고 재현하는 것이다. 메인 프로젝트에 가져갈 기능도 이곳에서 독립적으로 검증할 수 있다.

## 배치

- `src/`: ROS 2 패키지. 과제별 패키지를 만들며 패키지명은 소문자·밑줄을 사용한다. 예: `mini_gripper_practice`.
- `docs/`: 과제별 목표, 실행 방법, 실패 원인, 결과와 복습 노트.
- `exercises/`: DRL·Dart 등 ROS 패키지가 아닌 과제를 차시별 하위 폴더에 보관한다. 실행 계층을 명시하고 Python 파일이라는 이유로 ROS 노드와 같은 환경에서 실행하지 않는다.

강사 예시의 `src/DoosanBootcamInt1`, `src/onrobot_rg2`는 외부 설치 패키지 위치다. 현재 소스는 제공되지 않아 이 폴더들을 가짜 패키지로 만들지 않았다. 출처·버전을 확인하고 [의존성 기록](../docs/DEPENDENCIES.md)에 남긴 뒤 로컬에 준비한다. 메인 프로젝트의 `ws_dsr`를 이 수업 환경과 동시에 source하지 않는다.

## 과제 완료 기준

1. 입력·출력과 사용하는 제어 계층을 설명한다.
2. 실행한 환경·버전과 실제 시험 결과를 기록한다.
3. 실패한 조건과 아직 확인하지 못한 내용을 남긴다.
4. [실습 기록 양식](docs/EXERCISE_TEMPLATE.md)을 작성하고 담당 동료가 검토한다.

메인 프로젝트로 기능을 옮길 때는 별도 Issue와 PR을 만든다. 검증된 로직만 가져오며 경로·장비 설정·미완료 실험을 그대로 복사하지 않는다.
